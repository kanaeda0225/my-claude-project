# 業界アツさ × 市場注目度 マトリクス

> 2026年5月時点のスナップショット。スコアは独自評価。
> - **アツさ (H)**: 構造的追い風の強さ。5=爆風 / 4=強い順風 / 3=フラット / 2=向かい風 / 1=斜陽
> - **注目度 (A)**: 投資家・メディアの視線の集まり方。5=過熱 / 4=本命視 / 3=平均 / 2=見られていない / 1=忘却
> - **GAP = H − A**: プラス方向が大きいほど「実力に対して注目が薄い穴」候補。マイナスは「期待先行・過熱」候補。

## キーテイク

### ✅ 本命 (象限①: H=4-5 × A=4-5)
- **「AI × 電力 × 半導体」三位一体**は依然主役。ただし織り込みは厚く、リターン創出にはサプライチェーンの「次の細部」(冷却、変圧器、後工程材料、CPO) を見る必要がある。
- インバウンド・国内ホテルは数値が出続け、上方修正サプライズの再現性が高い。

### 🎯 穴 (象限②: H=4-5 × A=1-3) — **最も妙味**
1. **電気・空調サブコン / データセンタ建設サブコン**: AIインフラ投資の真の受益者だが地味。
2. **送配電・変圧器・グリッド近代化**: 期間3〜5年は受注確度高い構造ロング。
3. **介護人材 / 外国人材紹介**: 人口動態という最大の確定情報なのに人気がない。
4. **資産運用業 (日本)**: 新NISAでフローからストックの段階へ。
5. **CPO / シリコンフォトニクス**: AIインフラ次のレイヤー、まだコンセンサスではない。
6. **自動車アフターマーケット / 動物医療**: 確実成長、株式市場の関心度が低い。
7. **葬儀・終活**: 死亡数ピーク2040年に向け、地味で粘り強い成長。

### ⚠ 過熱注意 (象限③: H=1-3 × A=4-5)
- **ヒューマノイド・SMR・全固体電池・量子**は注目度が実態より先行。テーマ性で買うなら短期、長期は時間軸ミスマッチを覚悟。
- **GLP-1**は薬効・市場規模は本物だが、株価のピーク既反映を意識。

### 🪦 斜陽 (象限④: H=1-2 × A=1-2)
- **太陽光パネル/リチウム/車載LIB/水素/純EV**: 2021-2023年テーマの逆回転局面。バリュエーション割安は出るが、構造的供給過剰でカタリストが弱い。
