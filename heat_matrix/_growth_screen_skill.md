# 成長ストーリースクリーニングスキル

## このスキルのゴール

「この銘柄、伸びるかも」という仮説を2軸で構造化する。

- **マクロ軸**：業界・テーマ全体に追い風が来ているか
- **ミクロ軸**：この会社固有の成長ドライバーが存在するか

各軸に対して、以下の2つを必ず明らかにする：

1. **程度**：仮に成長した場合、全社P&Lにどれだけ効くか（セグメント構成比 × 成長倍率）
2. **時間軸**：変曲点は今か、先か（「今まさに変化が始まっている」か「まだ先の話」か）

判定・スコアは出さない。情報を整理して終わり。

---

## 検索戦略（10〜15回）

### フェーズ1：セグメント構造の把握（3〜4回）

「程度」の計算に必要なセグメント構成比を確認する。これが土台。

- `[銘柄名] セグメント 売上構成 営業利益`
- `[銘柄名] 決算短信 最新` → 各セグメントの売上・営利を数値で確認
- `[銘柄名] 事業内容 収益構造`

ここで以下を確認する：
- 各セグメントの売上・営利の絶対値と構成比
- どのセグメントが利益の主力か（営利率が高いセグメントはどこか）
- 「程度」を計算する際の起点となる現状値

### フェーズ2：マクロ軸の調査（3〜4回）

- `[業界テーマ] 市場規模 成長率 2025 2026`
- `[主要顧客の業界] 設備投資 需要 最新`
- `[銘柄名] 業界 追い風 テーマ`
- `[関連マクロテーマ] 日本 市場動向`

### フェーズ3：ミクロ軸の調査（3〜4回）

- `[銘柄名] ニュース 直近` → 直近1〜3ヶ月のカタリストを把握
- `[銘柄名] 業績修正 新工場 受注 提携 2025` → 変曲点事象を確認
- `[銘柄名] 競合 シェア 優位性`
- `[銘柄名] 中期経営計画 成長戦略`

### フェーズ4：変曲点の検証（1〜3回）

ここが最重要。「今が変曲点か」を裏付ける事実を探す。

- `[銘柄名] [変曲点候補の事象] 詳細`（例：「〇〇 新工場稼働」「〇〇 M&A 統合」）
- `[銘柄名] 適時開示 最新`

## 程度の計算方法

各セグメントの業績インパクトは以下のシンプルな試算で出す：

```
対象セグメント売上 ÷ 全社売上 = 構成比（売上）
対象セグメント営利 ÷ 全社営利 = 構成比（営利）

もしこのセグメントが○倍になれば：
→ 全社売上への影響：構成比（売上）×（成長倍率 − 1）= +○%
→ 全社営利への影響：構成比（営利）×（成長倍率 − 1）= +○%
```

**シナリオの成長倍率は固定値（×1.5/×2/×3）を使わない。「この会社がなぜ伸びるか」の源泉を先に特定し、そこから倍率を逆算すること。マクロCAGRが起点とは限らない。**

### シナリオ設定の手順

1. **成長の源泉を先に特定する（最重要）**

   成長倍率は「どこから来る成長か」によって根拠が変わる。以下のパターンから該当するものを選び、それに合った数字を探す。複数が重なる場合はそれぞれ分けて考える。

   | 成長の源泉 | 参照すべき数字 |
   |-----------|-------------|
   | 市場全体の拡大（マクロ） | 業界CAGR、市場規模予測 |
   | 顧客の発注量・設備投資増 | 顧客の中計・設投計画、受注残 |
   | 自社シェアの拡大 | 現在シェア、競合撤退・再編の状況 |
   | 製品単価・ミックスの改善 | ASP推移、高付加価値品の構成比変化 |
   | 新用途・新市場への横展開 | 新規顧客数、新市場の規模感 |
   | 稼働率・生産能力の解放 | 現在稼働率、新工場・新ライン計画 |
   | ストック積み上げ・リカーリング化 | ARR・ストック売上の推移と上限感 |
   | コスト構造の変化（固定費吸収） | 損益分岐点、先行投資の解消時期 |

2. **調査で必ず拾う数字（フェーズ1〜3で確認）**
   - 上記の源泉に対応する具体的な数値（CAGR、シェア、稼働率、ASP など）
   - 同社の直近3〜5年の当該セグメント売上CAGR（実績。過去の伸び方の参照点として）
   - 中期経営計画の売上・営利目標（あれば。Baseの上限感として使う）

3. **Bear / Base / Bull の定義**
   - **Bear**：成長の源泉が想定より効かないシナリオ。競合激化・顧客の投資延期・需要一巡・為替逆風などを織り込む。「なぜ伸びないか」を具体的に書く。
   - **Base**：最も蓋然性が高い中心シナリオ。会社ガイダンス・中計目標・現在の受注トレンドに素直に乗った場合。
   - **Bull**：成長の源泉が複数同時に効いた場合。過去最高成長ペース、シェア大幅拡大、想定外の新用途開拓などを想定。

4. **倍率の導出例（源泉別）**
   - 市場CAGR＋10%／年、評価期間3年 → Bear ≒ ×1.33、Base ≒ ×1.33〜1.6
   - 中計目標「3年で売上1.6倍」→ Base ≒ ×1.6
   - 稼働率が現在60%→フル稼働90%なら生産能力は×1.5が上限
   - シェアが現在15%→競合2社撤退で30%獲得なら売上は×2
   - 根拠が見つからない場合は「根拠なし・仮置き」と必ず明記する

## 変曲点の判定基準

変曲点は「期待」ではなく「事実」で判断する。以下のような**具体的な原因事象**があるかを確認する：

- 新工場・新拠点の稼働開始
- M&A統合の通期寄与が初めて反映される期
- 基幹システム刷新や先行投資コストの解消
- 法改正・補助金開始などの制度変化
- 顧客の設備投資サイクルの本格化（顧客の決算・計画から確認）
- 新事業の黒字転換

「業績が良くなりそう」という期待ではなく、「なぜその期から変わるのか」の原因事象を特定すること。

### マクロ超過α分解（★この銘柄がマクロCAGRを上回る理由）

> 問い：マクロ市場が年率+X%で伸びるとき、この会社の売上は本当に+X%で済むのか？それを上回るαは何か？

「マクロCAGR = 売上CAGR」のストーリーは弱い。良い銘柄は売上を「マクロ市場 × α1 × α2 × ...」と分解したとき、複数の因数が同時に伸びる構造を持つ。

**αドライバーの類型**（当てはまるものを最低1〜2個挙げる）：

- **員数増加（per unit）**：顧客1ユニットあたりの搭載・通過点数が増える（例：iPhone1台あたりカメラ数増、車1台あたりMLCC員数増）
- **ASP/ミックス上昇**：高機能化・高グレード化で単価が階段状に上昇
- **シェア拡大**：業界再編・競合撤退・規制強化で寡占化
- **用途拡大（横展開）**：同じ製品/技術が新市場へ波及
- **ボトルネック化**：供給制約や認証独占で値決め力を獲得
- **ストック化/サブスク化**：フロー売り→積み上げ型に構造転換
- **地理ミックス**：マクロを国内で見ても企業はグローバル（または逆）

**[この銘柄のα分解（自分の言葉で記述）]**

```
売上 = [マクロ要因] × [α1] × [α2]
マクロCAGR：+〇%／年
当社売上CAGRの想定：+〇%／年（=マクロ +α）
α超過分の正体：[何が効いてマクロを上回るかを1〜2行で]
```

αが特定できない（マクロ連動でしか説明できない）場合は、その旨を正直に記述する。それは「ミクロのストーリーが弱い」シグナル。

## 出力上の注意

- 数値には必ず「いつの情報か」を付記する
