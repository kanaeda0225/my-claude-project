# 資産運用業 銘柄スクリーニングレポート

**作成日**: 2026-05-16  
**テーマ**: 新NISA制度（2024年〜）が構造的AUM成長ドライバーとなる「資産運用業」ピュアプレー上場銘柄  
**対象市場**: 東証プライム・スタンダード・グロース全市場  
**スクリーニング基準**: 時価総額100〜4,000億円 / 日次売買代金 >1,000万円 / PER過熱でないこと  
**除外基準**: 大手金融グループ傘下で単独上場でないもの（野村HD・大和HD・三井住友トラスト等の大型財閥系）

---

## 1. 市場概観

### 新NISAによる構造変化

2024年1月から開始した新NISA（少額投資非課税制度）は、年間投資枠を旧NISA比で約3倍（つみたて投資枠120万円＋成長投資枠240万円=年間360万円）に拡大し、恒久化・非課税保有限度額1,800万円を設定した。これにより日本家計の「貯蓄から投資へ」のシフトが加速している。

**主要マクロ指標（2026年5月時点）**

- 投資信託純資産残高：約220兆円超（2025年末時点、過去最高水準更新中）
- 新NISA口座数：2024年末時点で約2,600万口座超（2023年末比+約800万口座）
- 運用会社AUM全体：新NISA経由の資金流入が月間数千億円規模で継続
- 信託報酬率：競争激化で低下傾向（eMAXIS Slim系 0.05〜0.1%台）が継続。低コストETF・インデックス運用への移行が加速

**業界構造上の特徴**

- 投信会社はSBI・三菱UFJ・野村・大和等の大手グループが過半のシェアを持つ
- 純粋独立系として東証単独上場している運用会社は極めて少ない
- IFA（独立系金融アドバイザー）は新規チャネルとして急成長しているが、上場法人は限定的
- ロボアドバイザー上場企業（ウェルスナビ）は2025年3月に三菱UFJ銀行TOBにより上場廃止

**競争環境の変化**

eMAXIS Slim等の超低コストインデックスが市場を席巻する一方、アクティブ運用・個別コンサルティング・IFAビジネスは差別化軸として存在感を増している。新NISA恒久化により長期的なAUM積み上げが見込まれるが、運用会社は手数料率低下との綱引きが続く。

### 5-1. SBIグローバルアセットマネジメント（4765）

**調査日**：2026-05-16  
**情報鮮度**：最終決算 2026年3月期（通期実績） ／ 直近株価 604円（2026-05-15）

| SBIレオスひふみ（旧レオス） | 約90 | 約32% | 2024年M&A統合。ひふみブランドAUM維持 |
| SBIボンドインベストメントMgmt他 | 約70 | 約25% | 債券系・海外子会社等 |
| 全社合計 | **278.6** | 100% | 前期比+141%（M&A効果込み） |
| 営業利益（全社） | **51.5** | — | 前期比+127%、17期連続増益 |

> ※ 2026年3月期実績。M&A前期（SBIレオスひふみ統合）の通期寄与が初めて反映された期。

#### マクロ軸

**ストーリー**：新NISA恒久化で家計金融資産の投資信託シフトが構造的に加速。SBIグループは口座数3,000万超の最大手SBI証券を通じた分配網を持ち、同経済圏内の資金流入が他の運用会社と比較してダイレクトに恩恵を受ける。SBI証券ユーザーの投信積立設定率の上昇がグループAUM拡大に直結する構造。

**程度（業績インパクト試算）**：AUM成長全社直結型

| シナリオ | 根拠 | AUM成長倍率（3年） | 売上インパクト | 営利インパクト |
|---------|-----|-----------------|------------|------------|
| Bear | 信託報酬率低下が加速、競合との価格競争でネット手数料率-20%、新NISAの資金流入が一巡 | ×1.3 | +20%程度 | +10%（報酬率低下で利益率圧縮） |
| Base | 新NISA継続流入、AUMが13兆→18兆（年率+11%×3年）、信託報酬率は小幅低下で安定 | ×1.5〜1.7 | +40〜50% | +40%（運用残高比例で固定費吸収） |
| Bull | SBI経済圏のAUM独占寡占化、レオス統合によるアクティブ需要取込、グループシナジー最大化 | ×2.0以上 | +80%以上 | +100%超（レバレッジ効く） |

**時間軸**：今まさに変化が始まっている  
**根拠となる事実**：2024年1月新NISA開始により資金流入が構造変化。2025年SBIレオスひふみ統合完了、2026年3月期でその通期貢献が初めて反映。AUMが13兆円を突破（過去最高）、17期連続増益達成。

#### ミクロ軸

**ストーリー**：SBI経済圏（SBI証券の口座数3,000万超）の独自分配チャネルにより、他の独立系運用会社が持てない顧客獲得チャンネルを内製化している。信託報酬率が業界全体で低下している中でも、規模の経済とSBI証券経由のゼロコスト獲得（広告費不要）が競争優位の核心。SBIレオスひふみ統合でアクティブ運用ブランド（ひふみ）も獲得し、インデックスとアクティブの両輪体制が整った。

**α分解**：

```
売上 = AUM残高 × 平均信託報酬率
マクロCAGR（投信市場全体）: 約+10%/年
当社AUM成長率（実績）: +30〜40%/年（M&A除く有機成長でも+15〜20%）
α超過分の正体:
  1. SBI証券経由の低コスト顧客獲得（分配網の内製化）
  2. SBIレオスひふみ統合によるAUM積み上げ（M&A的αドライバー）
  3. 規模拡大による固定費の分散（運用会社の典型的なレバレッジ構造）
```

**時間軸**：変化の途中（本格拡大フェーズ）  
**根拠となる事実**：2026年3月期売上が前期比+141%（統合初通期効果）。AUM 13兆円突破で規模効果が本格発現。次の変曲点は「AUM 20兆円突破」を目指すフェーズ（同社目標）。

**未解決の論点**：
1. SBI証券との利益相反（SBI証券がSBIGAM以外のファンドも販売する中で、内部取引の公正性）
2. 信託報酬率低下のスピード感（特にインデックスファンド競争が続く場合の利益率への影響）
3. レオスひふみのAUM（旧レオス時代から流出傾向があった）の実態

```
当社売上CAGR: 過去3年で年率+15〜20%程度
α超過分の正体: コンサルタント増員（数の拡大）×AI活用による生産性向上（効率化）
```

**時間軸**：変化の途中  
**根拠となる事実**：2026年よりAI活用による生産性向上施策を本格展開（IR情報）。新規拠点開設継続。16期連続増配で株主還元も安定的。

1. 不動産取引売上の変動性（2026年12月期減収予想の内実）
2. 証券・NISA関連収益の継続性（2025年の+45.8%が一時的か構造的か）

### YoY加速度 (前年差)
- 営業利益YoY: FY2024(+大幅) → FY2025(+3.2%) → FY2026(+17.0%) → **加速度はV字回復型** (一旦減速→再加速)
- 純利益YoY: FY2024(+大幅) → FY2025(**-19.4%**) → FY2026(+21.6%) → **減益→増益への振れ戻し** (純粋な加速ではない)

### 成功報酬の比率と変動性
- FY2024/3の利益急増は「成功報酬計上 + 有価証券売却益13億円」が大きく寄与 (一過性要因)
- FY2025/3は成功報酬が前年比 -7.6%と減少、純利益が -19.4%減と大きく落ち込み → **成功報酬への依存度が高く業績変動大**
- FY2026/3は「成功報酬の大幅増」が増益の主因 → 再び成功報酬主導

## B. 変曲点の所在

- **場所**: **過去確定 (FY2026/3 通期、2026年5月上旬発表)**
  - 「営利+17%・純利益+21.6% (過去最高)」は**FY2026/3通期実績**であり、進行中の四半期や予想ではない
  - **既存レポートの2nd Passは数値の年度を正しく把握している** (誤りなし)

- **過去5年で過去最高益を更新した回数**:
  - FY2024/3: **当時の過去最高純利益** (約65億円推定) を記録
  - FY2025/3: **減益** (52.52億円) → 過去最高更新せず
  - FY2026/3: **63.84億円で再び過去最高更新** (ただしFY2024/3比では微増程度の可能性)
  - **2年ぶりの過去最高更新** = **毎年更新の安定成長ではない (=非線形性の根拠が弱い)**

- **駆動要因**:
  - **株式市場上昇 ◎**: AUMの約70%が日本株 (1兆2,925億円/1兆8,720億円, FY2024/3末) → 日経平均・TOPIXとの相関が極めて高い
  - **成功報酬 ◎**: FY2026/3増益の主因は会社自身が「成功報酬の大幅増」と説明 → 構造的なベース報酬の増加ではない
  - **organic AUM増 △**: AUM 1.89兆 (FY2024/3) → 2.23兆 (FY2026/3末) の +18% 増加のうち、相当部分は時価評価益 (日経平均上昇分) と推定
  - **M&A**: 直近大型M&Aの明確な兆候なし

- **新NISA直接受益度**: **低い**
  - スパークスはアクティブ運用 (国際優良日本株ファンド等) 中心、信託報酬率が高い
  - 新NISAつみたて投資枠の主流はeMAXIS Slim系の超低コストインデックス (三菱UFJ・SBI等が席巻)
  - スパークスは新NISAから直接的なAUM流入を大きく享受している証跡が乏しい (会社開示でも新NISA経由流入の定量数値は確認できず)

## C. 成長の質

### ベース報酬 vs 成功報酬
- FY2024/3 ベース報酬 (残高報酬, 手数料控除後) 117.27億円 (+6.49億円, +5.9% YoY)
- ベース報酬の成長率は**1桁前半%** = 構造的成長は緩やか
- 成功報酬は年度により大きく変動 (FY2024/3で大規模計上→FY2025/3で減少→FY2026/3で再び大幅増)
- → **業績変動の主因は成功報酬とAUM時価評価益、ベース報酬の伸びは緩やか**

### 戦略別構成 (FY2024/3末)
- 日本株式: 1兆2,925億円 / 1兆8,720億円 = **約69%が日本株運用** (株式市場連動)
- その他: 不動産 (現実資産)、宇宙フロンティアファンド、ものづくり未来ファンド、未来創生ファンド等
- 宇宙ファンド・PE系は**規模としてはまだ小さい** (構成比10%未満と推定) → 将来性はあるが現状の業績ドライバーではない

### 一過性要因
- FY2024/3: **有価証券売却益13億円**を計上 (一過性)
- FY2024/3-FY2026/3とも**成功報酬の計上タイミング**による振れ大
- FY2025/3の減益はFY2024/3一過性要因のはく落が主因 → 真の「成長減速」ではない可能性も

### AUM増加の質
- AUM 1.54兆 (FY2021/3) → 2.23兆 (FY2026/3末) = **5年で +45%**
- 同期間の日経平均 約27,000円 (2021/3末) → 約38,000-40,000円 (2026/3末) ≈ **+45〜50%**
- → **AUM成長率 ≒ 日経平均上昇率** = **新規流入よりも時価評価益が主体** (構造的な家計マネー流入による積み上げではない)

## D. 非線形性の判定

- **判定**: **Mixed (循環的回復 + 部分的な構造変化)**
  - 真の非線形 (構造的AUM増) ではないが、純粋な循環でもない (宇宙ファンド・PE等の新領域は確実に積み上がりつつある)

- **根拠**:
  1. **AUM成長率が日経平均上昇率とほぼ同程度** → 構造的家計マネー流入の証拠が弱く、市場連動性が高い
  2. **2年ぶりの過去最高更新** (FY2024→FY2025減益→FY2026更新) → 毎期更新の連続成長ではない
  3. **成功報酬の大幅増が増益の主因** = 単年要因による業績振れであり、再現性に疑問
  4. **ベース報酬の伸びは1桁前半%** = 構造的成長率は控えめ
  5. **新NISA直接受益のエビデンスが乏しい** = スクリーニングテーマ「新NISA構造的受益」との整合性が弱い
  6. **ポジティブ要素**: 4本柱戦略 (日本株/海外株/不動産/PE) で多角化進行中、宇宙ファンド等成長領域への展開は明確、AUM 3兆円目標を掲げ中期成長ビジョンは存在

## E. 投資判断への含意 (v4 補正済)

**最終評価**: **横断 TOP5 (v3 #3末席→v4 #5 微調整)**

### v3 → v4 補正の論点

v3 (3rd Pass 初版) で「TOP3末席もしくは2-3位に格下げ」と判定したが、v4 では「市場時価評価益依存」「市場ベータ」を**全AM業界共通の特性として減点理由から外す**。一方、新NISA直接受益という スクリーニングテーマとの相性は弱いため、松井証券 (8628) などより構造的なAUM流入を享受する銘柄を上位検討対象とし、スパークスは TOP5 が妥当。

### 保持すべき致命的事実

1. **過去最高益は連続更新ではなく2年ぶり** (FY2024→FY2025 減益→FY2026 更新)
2. **成功報酬依存による業績ボラティリティ大** (FY2025/3 は -19.4% 減益、市場局面次第で減益転換)
3. **新NISA直接受益のエビデンスは乏しい** — 高コストアクティブ中心でつみたてNISA主流から外れる
4. **AUM 増加の大半は市場時価評価益**、ベース報酬の伸びは1桁前半%

### 評価維持の根拠

- 純粋AM・独立系・東証プライム・流動性十分・PER過熱なしというスクリーニング適合性は高い
- AUM 2.23兆円、4本柱戦略 (日本株/海外株/不動産/PE) で多角化進行中
- 宇宙ファンド等成長領域への展開は明確、AUM 3兆円目標を掲げる
- 営利+17%・純利益+21.6% の過去最高益自体は事実として確認済み

### 投資スタンス

**「市場上昇期に大きく稼ぐ高ベータAM」**として認識し、市場循環の局面を踏まえた投資判断が必要。新NISA テーマ純度を重視する場合は松井証券 (8628) が代替候補。スパークスは中期的な多角化進行+宇宙ファンド成長で α を取りに行く戦略。
