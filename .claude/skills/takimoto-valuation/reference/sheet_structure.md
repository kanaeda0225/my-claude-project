# スプレッドシート行構造規約

## 列構成 (横方向)

| 列 | 内容 |
| :---- | :---- |
| A | ラベル(項目名、インデント付き) |
| B〜E (or n) | 年度(過去実績→予想を左→右) 例: FY24/12実 / FY25/12実 / FY26/12予 / FY27/12予 |
| 重要度列 | ★ / ★★ / ★★★ |
| 備考列 | 各行の仮定・出典・補足 |

行1 (A1) に「**従属変数=黒、独立変数=青**」と凡例を入れる。

## 行構造 (縦方向)

各セクションをこの順序で並べる。**業績タイプによってトップ部分(売上ドライバー)は柔軟に変わる**が、原価以下は概ね共通。

```
■ 【売上高】 セクションヘッダー
  売上高 合計 (黒・従属)
  　増収率 (黒・従属、%)

■ 【セグメント別売上】 ※業績タイプによって違う構造
  セグメントA (青・独立 or 黒・従属)
  　サブセグメントA-1
  　　ドライバーA-1-a (青・独立 ★★★)
  　　ドライバーA-1-b (青・独立 ★★)
  セグメントB (青・独立)
  ...

■ 【因数分解 ※業績タイプ別】
  例:メック型 物量×物理量
    GPU向け基板生産数 (★★)
    銅箔層数 (★★)
    銅箔面積 (★★★)
    使用量補正
  例:ムービン型 コホート
    1年目人数 / 1年目一人当たり売上
    2年目人数 / 2年目一人当たり売上
    3年目以降人数 / 3年目以降一人当たり売上
    定着率
  例:かわでん型 セグメント×粗利率改善
    新規案件売上 / 新規粗利率(★★)
    リニューアル売上 / リニューアル粗利率(★★★)
  例:AlbaLink型 1人粗利×営業人数
    1人粗利(★)
    1店舗あたり営業人数(★)
    店舗数(★★)

■ 【粗利】
  売上原価
  売上総利益
  　粗利率 (%)
  製品別粗利率 (該当する場合)

■ 【販管費】
  販管費 合計
  　給料及び賞与 (青・独立)
  　荷造運搬費 (青・独立、売上に比例 等)
  　貸倒引当金繰入額 (青・独立、据置)
  　賞与引当金繰入額 (青・独立)
  　役員賞与引当金繰入額 (青・独立)
  　株式報酬引当金繰入額 (青・独立)
  　退職給付費用 (青・独立)
  　研究開発費 (青・独立)
  　減価償却費 (青・独立、新工場分等)
  　その他 (青・独立)

■ 【利益】
  営業利益
  　営業利益率 (%)
  経常利益
  　営業外損益
  税金等調整前当期純利益
  法人税等
  　実効税率 (青・独立、%)
  親会社株主帰属純利益

■ 【工場稼働率 / 補助KPI】 ※業績タイプによって違う
  例:メック
    工場稼働率 (%)
    生産量 (トン、青・独立)
    工場キャパ (トン、青・独立 ★)

■ 【株価・PER感応度】
  発行済株式数 (千株、青・独立)
  EPS (円)
  　想定PER ベスト (青・独立)
  　想定PER ノーマル (青・独立)
  　想定PER ワースト (青・独立)
  目標株価 ベスト
  目標株価 ノーマル
  目標株価 ワースト

■ 【「織り込み済み?」反論】 ※必須
  時価総額 (百万円、据置で固定) (青・独立)
  連結純利益 Base (黒・従属、上記再掲)
  時価総額据置PER (黒・従属) ← 利益増で機械的に低下することを示す

■ 【ピア比較 (PER)】 ※必須、3社程度
  自社現状PER (青・独立)
  ピア① (青・独立、ビジネスモデル類似)
  ピア② (青・独立、業態類似)
  ピア③ (青・独立、その他軸 例:地域戦略/価格戦略)
  ※純粋同業がいない場合の多軸選定を明示する備考
```

## スタイル強制ルール (Pythonレンダラーが実装)

| 項目 | ルール |
| :---- | :---- |
| 数値書式 | 整数は小数なし(`#,##0`)、%は1桁(`0.0%`)、3桁カンマ区切り |
| セル内整列 | 全セル右揃え(ラベル列のみ左揃え) |
| インデント | A列は全角スペース1個ずつ追加(`indent=1` で「　」、`indent=2` で「　　」) |
| 色分け | 独立変数=青(`1F4E78`)、従属変数=黒(`000000`)、ヘッダー=白文字に濃灰背景 |
| セクションヘッダー | 太字 + 薄灰背景 |
| グリッド線 | 非表示 |
| 行・列固定 | C2固定(1行目+A,B列) |
| 重要度マーキング | ★/★★/★★★ をラベルから推定:「最重要」「核心」「最大の理由」→★★★、「重要」→★★、「補助的」→★ |

## 備考列の必須ルール

- **すべての青セル(独立変数)に備考を入れる** — レンダラーが青セルで備考空欄を検出すると警告
- 備考の書式パターン:
  - 出典明示: `IR / yuho開示 / Omdia / モルガン・スタンレーレポート` 等
  - 仮定の根拠: `据え置き / 売上に比例 / 過去5年トレンドから外挿` 等
  - 重要な前提: `27/12は新工場の人件費分込み / 法人税率は税効果会計後の実効税率`

## グラフ要件

最低3つのグラフを各シートに含める:

1. **売上+利益 (棒) + 利益率 (線・第二軸ドット付き)**
   - 棒: 売上高、粗利、営業利益
   - 線: 営業利益率(右軸)
2. **業績タイプ別の主要ドライバー (棒+線)**
   - メック: GPU向け売上の伸び (棒) + GPU生産数YoY (線)
   - ムービン: コホート別売上 (棒積み上げ) + 一人当たり売上 (線)
   - かわでん: 新規/リニューアル売上 (棒) + 粗利率 (線)
   - AlbaLink: 店舗数・営業人数 (棒) + 1人粗利 (線)
3. **シナリオ別目標株価 (棒)** — Bear/Base/Bull の比較

## 業績タイプ別の上部構造の柔軟性

業績ドライバーのトップ部分(売上の作り方)は業績タイプによって全く違う。Pythonでハードコードせず、markdownの因数分解式を読んでその通りに行を組み立てる:

| タイプ | 例 | 行の組み立て方 |
| :---- | :---- | :---- |
| 物量×物理量 | メック | ベースの生産数 × 物理量(層数/面積等) × 補正係数 を全部行として並べる |
| コホート | ムービン | 各年次のコホート(1年目/2年目/3年目以降)の人数行 × 単価行 をペアで並べる |
| セグメント×改善 | かわでん | セグメント別売上 と セグメント別粗利率の両方を時系列で並べる |
| 1人粗利×人数 | AlbaLink | 1人粗利(維持前提)、店舗あたり人数(維持前提)、店舗数(成長) の3因数 |
| 持分法 | 保土谷 | 親会社の独自業績 + 関連会社業績×出資比率 の2つを分けて算出 |

## 業績タイプの判定方法

入力markdownの 0️⃣セクション内 ``` ブロックを見る:
- 「× 面積 × 層数」のように物理単位 → 物量×物理量
- 「1年目 + 2年目 + ...」「コホート」 → コホート
- 「新規 + リニューアル」「セグメントA × 粗利率」 → セグメント×改善
- 「営業人数 × 1人粗利」「店舗数 × 店舗あたり人数」 → 1人粗利×人数
- 「持分法利益 = 関連会社純利益 × 出資比率」 → 持分法

判定したらタイプ名を備考に明記しておくと後の検証で参照しやすい。
