# スライド章立て規約

瀧本ゼミの発表スライドは5本のサンプル(メック/ムービン/かわでん/AlbaLink/保土谷)すべてで以下の章立てを共有する。

## 標準章立て

```
[1]   表紙 (銘柄コード + 社名 + 推奨 + 目標株価 + 投資期間 + 発表者)
[2]   ストーリー / 発表要旨 (3〜5行で結論まで言い切る)
[3]   発表を理解するための地図 (任意。3問の流れを示す)
[4]   因数分解スライド (式 + 因数表)
[5]   なぜ市場が気づいていないか (ミスプライシングの根拠表)
[6]   目次

[7-]  ▼ 1️⃣ 基本情報
        - 会社の概要 (時価総額・PER・PBR・カバレッジ等の指標表)
        - ビジネスモデルの全体像
        - 事業内容・主力製品
        - 用語解説 (「○○とは」型ブロック)

[--]  ▼ 目次再掲 (マクロへ)
      ▼ 2️⃣ マクロ
        - マクロ全体の流れ (任意。サブセクション前にサマリー)
        - 業界トレンド・市場規模
        - カタリスト
        - データ表 (成長率、シェア、需要等)
        - まとめ

[--]  ▼ 目次再掲 (ミクロへ)
      ▼ 3️⃣ ミクロ
        - 競合優位性 (Moat) 複数項目
        - 参入障壁
        - 競合分析
        - 経路図 (出資構造・流れ図)

[--]  ▼ 目次再掲 (バリュエーションへ)
      ▼ 4️⃣ バリュエーション
        - 現在の株価水準 (株価/時価総額/PBR/カバレッジ)
        - 数値の組み立て (売上 → 利益)
        - PER感応度・目標株価
        - シナリオ別 (Bear/Base/Bull)

[--]  ▼ 目次再掲 (Appendixへ)
      ▼ 5️⃣ Appendix
        - 投資期間の根拠 (いつ売るか含む)
        - ダウンサイドリスクとその打ち消し
        - 前回QAへの回答 (該当ある場合)
        - 現地調査レポート (該当ある場合)
        - 株価推移の評価
        - その他の追加カタリスト
```

## スライドのお作法

### 1スライド1メッセージ

- ヘッダー1行 + メイン領域(箇条書き3〜5項目 もしくは 1つの表/図)
- 長い箇条書きは2スライドに分割
- 詰め込みたい誘惑があったら捨象する
- AlbaLinkの「ボロ戸建てに行ってみた①」「②」のように同じトピックを2枚に分けるパターンOK

### 表の扱い

- markdownの表 → そのままスライドの表として表示
- 表が大きすぎる場合は重要列だけ抜粋
- 表のフォントは本文より1サイズ小さくしてOK

### ASCII図の扱い

- 構造図(出資関係・サプライチェーン・OLED構造等)はテキストで再現
- 等幅フォントを使い、レイアウトを保持
- 配置上難しい場合は `[画像: ○○の構造図]` プレースホルダにしてユーザーが手作業で挿入

### 用語解説スライド

サンプル中の `### **○○とは**` ブロックは独立スライド化する:
- ヘッダー: 「(補足) ○○とは」
- 内容: 定義 + アナロジー + 重要性
- 任意のタイミングで挿入

### 目次再掲

各章の冒頭(あるいは前章の末尾)に挿入。サンプルでは2〜4箇所。markdownでは明示されないので、章遷移を検出して自動挿入。

### 出典フッター

各スライドの底に小フォントで出典を入れる。markdownの末尾に書かれているソース(IR/レポート/業界紙)を該当スライドにマッピング。

```
出典: メックIR、モルガン・スタンレーレポート、イビデンIR
```

### トーン合わせ

入力markdown の文体に応じて:
- 熱量型(メック「BUY!!!」、かわでん「STRONG BUY!!」): エクスクラメーション残す、強気な見出し
- 分析型(保土谷): 抑制した断定、データ中心
- 物語型(ムービン「25年保守経営」): 時系列を見せる、変曲点を強調
- 体感報告型(AlbaLink「現地に行ってきた」): 体験談・一人称・具体引用

## 表紙のレイアウト

```
┌─────────────────────────────────────┐
│                                     │
│  【銘柄コード】 社名                 │
│                                     │
│  推奨：BUY (or STRONG BUY)          │
│  目標株価：○○○○円                 │
│  投資期間：○○                      │
│                                     │
│                                     │
│           ○○期 発表者名             │
└─────────────────────────────────────┘
```

- ムービン: `【421A】ムービン・ストラテジック・キャリア / 13.0 生田開都`
- かわでん: `6648 かわでん / 推奨：BUY / 株価：2300円 →4978円 (投資期間：1年〜2年弱) / 14.0期 庭野純之介`

## 因数分解スライドの定型

```
ヘッダー: 売上高の因数分解
本文:
   売上高 = [因数A] + [因数B]
   
   [因数A] = ... × ... × ...
   
   [因数B] = ... × ... × ...
```

- 等号と矢印で式を視覚化
- ASCII art OK
- markdownの ``` ブロックそのまま転記でよい
