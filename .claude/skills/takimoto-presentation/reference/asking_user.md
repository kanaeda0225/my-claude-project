# ユーザーへの質問の出し方

スキル実行中、以下のケースで AskUserQuestion を使う。**4問まで、各2-4選択肢、選択肢にはRecommended優先**。

## いつ質問するか

1. **業績タイプの判定に迷うとき** — markdownの因数分解が複数パターンに該当する
2. **PER感応度のレンジ** — 同業比較した上で Best/Normal/Worst のPERを決める
3. **ピア企業の選定** — 純粋同業がいないので多軸選定が必要
4. **シナリオの確率設定** — Bear/Base/Bull の確率割り当て
5. **トーン確認** — markdownの文体が読み取りにくいとき

## 質問テンプレート

### Q: PER感応度のレンジ

```
質問: 想定PERのレンジをどう設定しますか?
オプション:
  - [自社現状PERを中心に±20%] (Recommended)
  - [同業平均を中心に±20%]
  - [自分で指定する]
```

### Q: ピア企業の選定

```
質問: ピア比較に使う上場会社を選んでください(3社程度)
オプション:
  - [私が選ぶ: 業態/モデル/価格戦略の3軸で多軸選定] (Recommended)
  - [ユーザーが指定]
  - [ピア比較なしで進める(非推奨)]
```

### Q: 業績タイプ判定に迷うとき

```
質問: 業績ドライバーの分解方法は次のどれが近いですか?
オプション:
  - [① 物量 × 物理量(層数/面積等)]
  - [② コホート(経験年数別)]
  - [③ セグメント × 粗利率改善]
  - [④ 1人当たり粗利 × 人数]
  
  ※「⑤ 持分法」「ハイブリッド」もOther経由で選べる
```

### Q: トーン確認 (markdownの文体が判別しづらいとき)

```
質問: 出力資料のトーンはどれにしますか?
オプション:
  - [熱量型(「BUY!!!」のような強気な見出し)]
  - [分析型(数値と論理中心、控えめな断定)]
  - [物語型(時系列の語り、変曲点強調)]
  - [体感報告型(現地・体験談中心、一人称)]
```

## 質問しないでいいケース

- markdownに明示的な数値・選択がある → そのまま使う
- 一般的な実務慣行で決まる(法人税率25%等) → 補正値で進める
- 既存4本サンプルから明らかな選択(粗利率の典型値等) → サンプル参照して決める

## まとめてではなくスポット投入

「全部の不足項目を1度に4問」より、「ストーリーが固まる→PERだけ聞く」「ピアだけ聞く」のようにスポットで聞いた方がユーザー負担が低い。**Critical path にあるものを優先**。
