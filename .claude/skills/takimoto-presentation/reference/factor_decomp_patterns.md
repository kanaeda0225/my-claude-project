# 業績タイプ別 因数分解パターン

入力markdownの 0️⃣ セクション ``` ブロックから業績タイプを判定し、以下のパターンに沿って.xlsxの上部行を組み立てる。

## ① 物量 × 物理量 型 (例: 4971 メック)

**判定**: 因数分解の式に物理単位(mm², 層数, トン等)が含まれる

```
売上(全体) = セグメントA売上 + セグメントB売上 + ...

セグメントA売上 = 基準数量 × 物理量1 × 物理量2 × ... × 補正係数
```

**メックの実例**:
```
CZ売上 = 汎用向け + GPU向け

GPU向け = 基板生産数 × 銅箔層数(加重平均) × 銅箔面積(加重平均) × 使用量補正(50%)
```

**xlsx 行の組み立て**:
```
■ セグメント別売上
  薬品事業
  　密着向上剤(CZ)
  　　汎用向け  [独立、据置]
  　　GPU向け  [独立、★★★]   ← 因数分解で計算
  　エッチング剤  [独立、据置]
  　その他  [独立、据置]
  機械事業  [独立]
  資材事業  [独立]

■ 因数分解 (GPU向けCZ)
  基板生産数(相対値)  [独立、★★]
  　YoY  [従属]
  銅箔層数(加重平均)  [独立、★★]
  　Hopper比率  [独立]
  　Blackwell比率  [独立]
  　Rubin比率  [独立]
  銅箔面積(mm², 加重平均)  [独立、★★★]
  　Hopper面積  [独立]
  　Blackwell面積  [独立]
  　Rubin面積  [独立]
  使用量補正  [独立]
```

## ② コホート(経験年数) 型 (例: 421A ムービン)

**判定**: 経験年数別の人数 × 単価の和、定着率がある

```
売上 = 1年目人数 × 単価 + 2年目人数 × 単価 + 3年目以降人数 × 単価

別の見方:
売上 = 成約数 × 成約単価
成約単価 = 転職後年収 × 手数料率
```

**xlsx 行の組み立て**:
```
■ 売上構造
  売上合計
  　1年目コホート売上
  　　1年目人数  [独立、★]
  　　1年目一人当たり売上  [独立、★]
  　2年目コホート売上
  　　2年目人数  [独立、★]
  　　2年目一人当たり売上  [独立、★]
  　3年目以降コホート売上
  　　3年目以降人数  [独立、★]
  　　3年目以降一人当たり売上  [独立、★]

■ 補助指標
  定着率1年目  [独立、据置]
  定着率2年目以降  [独立、据置]
  成約単価上昇率  [独立]
```

## ③ セグメント × 粗利率改善 型 (例: 6648 かわでん)

**判定**: セグメント別売上に加えて、セグメント別粗利率が時系列で改善する

```
売上 = 新規 + リニューアル
粗利 = 新規 × 新規粗利率 + リニューアル × リニューアル粗利率
```

**xlsx 行の組み立て**:
```
■ セグメント別売上
  売上合計
  　新規案件  [独立、★]
  　リニューアル  [独立、★★★]

■ セグメント別粗利率
  新規粗利率  [独立、★★]
  　新規収益改善率(YoY)  [独立、★★]
  リニューアル粗利率  [独立、★★]
  　リニューアル収益改善率(YoY)  [独立、★★]
```

## ④ 1人粗利 × 営業人数 型 (例: 5537 AlbaLink)

**判定**: 1人当たり指標 × 人数 × 店舗数

```
粗利 = 1人粗利 × 営業人数
営業人数 = 店舗数 × 1店舗あたり営業人数

別の見方:
粗利 = 販売単価 × 販売件数 - 仕入単価 × 仕入件数 + 有料引取代金 × 有料引取件数
```

**xlsx 行の組み立て**:
```
■ 売上総利益構造
  売上総利益
  　1人粗利(半期、据置)  [独立、★]
  　営業人数(年平均)
  　　店舗数  [独立、★★]
  　　1店舗あたり営業人数  [独立、★、据置]

■ 検算用 (件数ベース)
  販売単価  [独立]
  販売件数  [独立]
  仕入単価  [独立]
  仕入件数  [独立]
  有料引取代金  [独立]
  有料引取件数  [独立]

■ 1人粗利の維持理由 (補助KPI)
  1人あたりリード数  [独立]
  成約率  [独立]
  1件あたり粗利  [独立]
```

## ⑤ 持分法 型 (例: 4112 保土谷化学)

**判定**: 連結業績の主体が関連会社の持分法利益

```
連結純利益 = 親会社独自純利益 + 関連会社純利益 × 出資比率

関連会社売上 = 売上ドライバー(物量×単価等)
関連会社純利益 = 関連会社売上 × 粗利率 - 販管費 - 法人税
```

**xlsx 行の組み立て**:
```
■ 売上ドライバー (関連会社側)
  関連会社売上総需要
  　ドライバー1  [独立、★★★]
  　ドライバー2  [独立、★★]
  ...

■ 関連会社損益
  関連会社売上高
  関連会社原価率  [独立]
  関連会社粗利
  関連会社販管費  [独立]
  関連会社営業利益
  関連会社法人税率  [独立]
  関連会社純利益

■ 連結損益
  親会社単独事業 売上  [独立]
  親会社単独事業 純利益  [独立]
  関連会社からの持分法利益(×出資比率)
  連結 親会社株主帰属純利益
```

## 判定フローチャート

```
markdownの 0️⃣ 因数分解 ``` ブロックを読む
   │
   ├─ 物理単位(mm², 層数, トン, kg)が含まれる
   │     → ① 物量×物理量
   │
   ├─ 「1年目」「2年目」など年次・経験別の人数が並ぶ
   │     → ② コホート
   │
   ├─ セグメント名 × 粗利率(改善) の組み合わせ
   │     → ③ セグメント×改善
   │
   ├─ 「店舗数」「営業人数」「1人粗利」が中心
   │     → ④ 1人粗利×人数
   │
   ├─ 「持分法」「出資比率」「関連会社」が中心
   │     → ⑤ 持分法
   │
   └─ どれにも当てはまらない / 複数該当
         → markdownの式をそのまま実装、判別困難ならユーザーに確認

```

## ハイブリッドケース

実際の発表では複数のパターンが混ざることがある:

- **ムービン**: ② コホート と (成約数×成約単価) の2方向分解(検算用)
- **AlbaLink**: ④ 1人粗利×人数 と (販売件数×単価)の2方向分解 + ⑤ 三為取引比率という補助因子
- **保土谷**: ⑤ 持分法 だが、SFC自体の売上は ① 物量×物理量(IT-OLEDパネル枚数×面積×積層数)

→ 主軸を1つに決めつつ、補助の検算ブロックも入れるとロバスト。
