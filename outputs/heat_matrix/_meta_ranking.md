## 1. v3 改訂版 横断 TOP10

v3 では「**真の非線形性の濃度**」を最重要視して再順位付け。**真の非線形要素を持つ銘柄を上位に、期待先行/循環的回復が主因の銘柄を下位に降格**。

### 🥇 第1位: **鎌倉新書 (6184)** — 葬儀・終活
- **3rd Pass の真の発見**: 売上+26%ガイダンスは過去5年レンジ内で特別な変曲ではない、しかし**利益面で営利率 13% 帯 → 16.2% 予想に拡張** = 過去5年で初めての構造シフト。介護黒字化+官民協働の貢献。
- **非線形要素**: 営利成長率が 2022-2024年に減速 → 2025年から **V字回復** (+11.6%→+27.6%→予 +46.3%)。
- **真の理由でTOP1**: 横断10銘柄で「利益面の非線形」を新規発生として確認できる唯一の銘柄。
- **留意**: 相続・不動産事業は -16.3% 減収 (大手競合台頭)。

### 🥈 第2位: **湖北工業 (6524)** — CPO/光通信
- **真の非線形要素**: 海底ケーブル用光アイソレータ世界シェア50%超、光部品・デバイス事業は構造成長フェーズ。FY2025/12 売上+15%、FY2026/12 Q1 で **売上+27.7%・営利+81.5%** に再加速。
- **留意**: Q1 経常+4.4倍の大部分は為替差益 (一過性)、リード端子事業の循環性、過去5年は非リニア (FY2023 で-14%急落)。
- **v3で2位昇格の理由**: 「光部品セグメント単独」では構造成長の証拠が最も強い。

### 🥉 第3位: **QPS HD (5595)** — 衛星画像
- **3rd Pass 注意**: 「2026年5月期黒字化」は経常ベースであり、営業損益では赤字続く可能性。
- **真の非線形要素**: 受注残 1,048億円・防衛省コンステ 697億の確定性・36機体制への明確なロードマップ。**売上の非線形成長は確定的**、利益変曲は3-4年先。
- **留意**: 短期 (FY2026-FY2027) は減価償却負担と増資による希薄化リスク。

### 第4位: **スパークス・グループ (8739)** — 資産運用業
- **真の特徴**: 純粋AM、営利+17%・純利益+21.6% (過去最高)。
- **3rd Pass の警告**: AUM増加の大半は**市場時価評価益**、ベース報酬は1桁台成長、過去最高益も2年ぶり (連続更新ではない)。**高ベータAMとして市場循環の局面を踏まえた投資判断が必要**。
- **新NISA直接受益というスクリーニングテーマとの整合性は弱い** (高コストアクティブ運用)。

### 第5位: **ANYCOLOR (5032)** — 日本IP流通
- **3rd Pass の警告**: Q1 +157.6% は前期Q1 -32.8%からのベース効果、2年CAGR +32% でほぼリニア。
- **維持の理由**: 営利率40%超の優良高収益IPプラットフォーム、にじさんじIPの強さ。
- **留意**: 海外拡大の証拠は決算データでは限定的。

### 第6位: **日本動物高度医療センター (6039)** — 動物医療
- **3rd Pass の警告**: 過去の +23.6% は大阪拠点通年寄与の一回限り段差。FY2026/3 通期予想 +12.9% に減速。
- **維持の理由**: 二次診療の構造的需要 + 利益率改善 + 新患数記録更新は本物。次の拠点開設まで段差待ち。

### 第7位: **KeePer技研 (6036)** — 自動車AM
- **3rd Pass の致命傷**: 実数値はリニア減速、期待のみが先行。FC展開50社申込は数値の根拠としては弱い (まだ売上に表れていない)。
- **大幅格下げ**: TOP1 → 7位へ降格。中計目標が達成されるかは数年かけて見る必要あり。

### 第8位: **日本電技 (1723)** — 電気・空調サブコン
- **3rd Pass の警告**: 営利率変曲 (13%→25%) は FY2024 で既発生済。現在は売上加速度ピークアウト。

### 第9位: **ミライト・ワン (1417)** — DC建設サブコン

## 4. 3rd Pass で得られた本質的な学び

### A. 「変曲点」を語る企業の多くは既に変曲点を過ぎている
日本電技 (営利率変曲は FY2024 既発生)、JARMeC (拠点ジャンプは FY2025/3 既発生)、ANYCOLOR (ベース効果でのリバウンド) など、「直近の決算で +XX% 増益」というのは多くの場合「**過去の構造変化が今表面化した結果**」であって「これからの非線形成長」ではない。

### B. ストーリーと実数値の乖離
KeePer技研 (FC展開ストーリーは強いが実数値は減速)、ミライト・ワン (DC需要受益はナラティブで実態は循環+M&A) など、**ストーリーが投資家を惹きつける銘柄ほど、実数値は期待に届いていないリスクが高い**。

### C. AUM/受注残ベースのビジネスは "売上の非線形性" と "利益の非線形性" が時間差で発生
QPS HD は売上は非線形成長確定だが営業利益黒字化は3-4年先。スパークスはAUM増えてもベース報酬は1桁台。**売上と利益のタイムラグを意識**しないと「変曲点」の所在を見誤る。

### D. ベース効果の罠
ANYCOLOR の Q1 +157.6% は前期Q1 -32.8%からの反動が主因で、2年CAGRで見れば +32% の線形成長。**前年同期が異常値だった場合のYoY%は割り引いて見るべき**。

### E. M&A・FX・一過性要因の混入
湖北工業 Q1 経常+4.4倍は為替差益、ミライト・ワン利益増にはM&A効果、JARMeC は新拠点ジャンプ。**「真の非線形」と「構造+循環+一過性の合算」を見分ける厳しさ**が必要。

### F. 結論: 真の非線形成長は希少
13業界×3銘柄=39候補のうち、横断TOP10に絞り、さらに 3rd Pass で「真の非線形成長」と認定できたのは**実質1-3銘柄程度** (鎌倉新書の利益面、湖北工業の光部品セグメント、QPS HDの売上)。投資家として、この希少性を認識した上で銘柄選択するのが本ファイル群の最大の学び。

## 6. 留意事項

### 投資アドバイスではない
本レポート群は構造分析+事実検証+変曲点検証であり、個別の売買推奨ではない。実投資判断は個別企業の最新IR/決算と財務を必ず独自に再検証のうえで。

### "真の非線形" の希少性
3rd Pass の最大の学びは、**「市場で語られる変曲点ストーリーの多くは、既発生 (過去) か / 期待先行 (将来) か / 一過性混入 (FX・M&A・ベース効果) のいずれか**で、純粋な「これから始まる非線形成長」と言える銘柄は極めて希少**ということ。本ランキングはその希少性を可視化したものに過ぎない。

### 次のステップ
- TOP3 (鎌倉新書、湖北工業、QPS HD) について個別深掘り (財務モデル、競合分析、リスク評価)
- 横断TOP10圏外で 3rd Pass を実施していない銘柄群のうち、各業界2位3位 (eWeLL、ANYCOLOR以外のIP)、新NISA直接受益銘柄 (松井証券 8628 の方がスパークスより構造的かも) を改めて検討
- ユニバース外候補 (時価総額外れ値・上場間もない銘柄) の再吟味
