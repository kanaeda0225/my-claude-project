## 1. 市場概観

### 市場定義

地球観測衛星（光学・SAR・ハイパースペクトル）、画像解析サービス、GIS/デジタル地図、航空・ドローン測量、インフラ点検・農業・保険・防衛向け画像アナリティクスを含む。

### マクロ環境（2026年5月時点）

**防衛需要（最大の推進力）**
- 防衛省は2024年12月、「衛星コンステレーション整備・運営等事業」を三菱電機・スカパーJSAT・三井物産を代表とするSPVと、QPS研究所・Synspective・アクセルスペース等7社で落札。総事業規模2,831億円、事業期間は2031年3月末まで（約5年間）。
- スタンドオフ防衛能力確保のための画像情報安定取得が政策目的。衛星コンステレーション整備に民間活用を本格推進。

**宇宙戦略基金（JAXA主管）**
- QPS研究所：上限約212億円（2028年度末まで）採択。小型SARの量産加速・機能強化。
- Synspective：約164.6億円採択（2027年3月まで）。SAR30機体制構築加速。
- アクセルスペース：次世代地球観測衛星向け観測機能高度化技術で採択（2026年3月）。

**商業需要**
- 農業・保険・ESGモニタリング・インフラ点検でのリモートセンシングデータ需要が拡大。
- 国土強靭化関連の航空測量・ドローン点群測量の官需も堅調。
- 自動運転向け高精度地図（ゼンリン等）。

**市場規模感**
- 衛星ベース地球観測市場：2031年114億ドル予測（CAGR7.2%）。
- リモートセンシング技術市場全体：2026年206億ドル予測（CAGR12.3%）。

### 業界の主要バリューチェーン

```
衛星製造・打ち上げ → 衛星運用・コンステレーション → 画像取得・データ処理
 → 解析・ソリューション → エンドユーザー（防衛/農業/インフラ/保険）
```

日本の上場ユニバースは「衛星製造・運用」と「地上データ活用（GIS・測量）」の2クラスターに大別される。

# 🚀 3rd Pass: QPS研究所 / QPS HD (464A、旧5595) 変曲点と非線形成長の検証 (2026-05-17)

**ティッカー確認**: 旧コード **5595 (QPS研究所)** は2025年11月27日付で上場廃止。2025年12月1日付で持株会社 **QPSホールディングス (464A)** が新規上場 (株式移転による完全親会社化)。実体は同一。決算は2026年5月期から連結ベース。

**重要な発見**:
- FY2025/5に営業利益が「341百万円黒字 (FY24) → ほぼゼロ」に**逆行**。利益は連続成長していない。
- FY2026/5は**売上は+49%増だが営業損失▲12億円に拡大**。経常+5-6億円・純利益+5億円の黒字は「補助金収入を営業外計上」する構造によるもので、本業ベースでは赤字深掘り。
- Q3累計で営業損失▲14.5億円・純損失▲1.8億円。会社予想 (純利益5億) には**Q4一発逆転を要する**。

## B. 変曲点の所在

- **変曲点の場所**: **未確定 (会社予想に依存)**。
  - 「FY2026/5 黒字化」と語られているのは**経常・純利益ベース**であり、**営業損益は▲12億円の赤字計画**。これは「本業黒字化」とは異なる。
  - Q3時点で売上は通期計画40億円に対し16.1億円 (進捗40%) → Q4で23.9億円の計上を要する。防衛697億の初年度2%弱 (=約14億) がQ4集中の蓋然性高い。
  - **本業 (営業) 黒字化のタイミングは早くてFY2027/5以降**。防衛697億の年度別配分が薄い (FY26: 2%未満 → FY27: 11% → FY28: 17%) ため、本業黒字化は防衛売上が17-24%乗ってくる**FY2028/5-FY2029/5が本命**。

- **駆動要因**:
  - **防衛省コンステ事業697億円**: 配分カーブが後ろ重い (FY26: 2% / FY27: 11% / FY28: 17% / FY29: 24% / FY30: 25% / FY31: 21%)。本格貢献は3年後以降。
  - **宇宙戦略基金212億 (2028年度末まで)**: 営業外の補助金収入として計上 → 経常・純利益を支えるが営業利益には貢献しない。
  - **商業契約 / 民間収益化**: 黎明期、寄与小。
  - **衛星機数増 (9機→24機→36機)**: 撮像頻度向上で商業データ販売余地を拡大するが、減価償却費も同時に増加。

- **売上計上タイミング**:
  - SAR画像データ販売: 撮像/データ納品時に計上 (フロー型)。
  - 防衛省コンステ: 役務提供期間にわたる**進行基準的な計上** (5年配分カーブ公表済み)。
  - 受注時計上ではないため、697億は契約済みでも段階的にしか売上化されない。

## C. 成長の質

- **受注残積み上がり**:
  - 累計受注 (補助金含む事業収益ベース) は**約1,048億円**まで膨張 (Q3時点)。FY2025/5までの累計150億円超から**約7倍**に拡大。
  - ただし大半が防衛697億 + 宇宙戦略基金212億で、**官公庁集中度が極端に高い**。

- **衛星機数 vs 売上の関係**:
  - 機数: FY23末2機 → FY24末4-5機 → FY25末6機 → FY26末14-15機予定 → FY28末24機 → 最終36機。
  - 売上は機数増のリニア関数では伸びていない (FY24→FY25は機数+50%・売上+62%、FY25→FY26予想は機数+150%超・売上+49%)。
  - **稼働開始衛星の減価償却費負担が売上増を相殺**する構造が明確化。

- **CAPEX / 減価償却の効き方**:
  - 償却対象衛星数: 2機 → 6機 (4倍化)。減価償却費は1Qで210百万円 (前年比+14%) と着実に増加。
  - 第三者割当増資 (2026年3月公表) で資金調達 → さらなる衛星投資を継続。
  - 衛星1機の耐用年数を概ね5年で償却する場合、24機体制時の年間減価償却は数十億円規模に到達 → 売上が3桁億円に乗らないと営業利益率は薄い。

- **黒字化後の利益率**:
  - 防衛省コンステ事業の単年売上ピークは年170-175億円 (FY30/5)。これに商業データ販売・宇宙戦略基金の経常寄与を合わせると、ピーク年間売上は250-300億円規模。
  - 減価償却控除後の営業利益率は**フェーズが安定すれば20-30%が射程**。ただしそれはFY2029/5以降のシナリオ。

## D. 非線形性の判定

- **判定**: **Mixed (混在型 — 売上は非線形、利益は線形回復に至らず)**

- **根拠**:
  1. **売上の非線形成長は事実**: FY22→FY23→FY24→FY25→FY26 の売上トレンドは18→372→1,653→2,681→4,000百万円。CAGR(FY23-FY26予想) で約120%。受注残1,048億円は売上40億円の26倍 → 数年スパンで非線形成長を裏付ける。
  2. **しかし利益は非線形でない**: FY24に営業黒字化 → FY25でほぼゼロに後退 → FY26は営業▲12億円に悪化。CAPEX先行・減価償却膨張により**利益は2026-2027年で凹む**。これは「変曲点を通過した」のではなく「コンステ拡張投資の谷」を進行中。
  3. **真の利益変曲点は3-4年先**: 防衛697億の配分カーブ (FY28: 17% / FY29: 24%) と減価償却の安定化が交差する**FY2028/5-FY2029/5**こそ本物の営業利益変曲点。
  4. **会社予想の「黒字化」は補助金頼み**: 営業外の宇宙戦略基金補助金で経常・純利益を黒字化する構造であり、本業ベースでは赤字継続。「黒字化転換」を額面通り受け取ると誤読のリスク。

## E. 投資判断への含意

- **横断TOP5評価**: **維持 (但しランクは要見直し)**
  - **維持の理由**: 受注残1,048億・防衛省コンステ697億の確定性・36機体制への明確なロードマップ・SAR国内寡占ポジションは依然として上場宇宙銘柄で最強級。**売上の非線形成長**は確定的。
  - **格下げ要素**: 「2026年5月期に黒字化」という主張は**営業損益ベースでは事実誤認**であり、本業の利益変曲点は3-4年先。短期 (FY2026-FY2027) では減価償却負担と増資による希薄化リスク (2026年3月第三者割当) で株価が冴えない展開もあり得る。
  - **再ランキング推奨**: 「衛星セクター内のTOP1」は維持しつつ、横断TOP5の中での順位は**「3-5年スパンの長期保有銘柄」枠**として位置づけ直す。短期モメンタム派には不向き。
  - **重要前提**: 2nd Pass で指摘した「営業赤字継続」「アストロスケールHD (186A) の存在感」を踏まえると、衛星セクター内でもアストロスケールHD (受注残411億・売上+194%・既に営業利益寄与) が短期モメンタムでは上回る可能性。**QPS HDは"長期受注バックログ確信枠"**としての評価が適切。
