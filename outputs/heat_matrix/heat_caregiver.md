# 介護・介護人材 セクター 銘柄スクリーニング＆Growth-Screen レポート

**作成日:** 2026-05-16  
**対象市場:** 東京証券取引所（プライム・スタンダード・グロース）  
**スクリーニング基準:** 時価総額100〜4,000億円、売買代金>1,000万円/日、PER業界相対（過熱除外）  

---

## 1. 市場概観

### マクロ環境（2026年5月現在）

**人口動態ドライバー（不変の構造）**
- 65歳以上の高齢者人口：約3,600万人（人口比約29%）、世界最高水準
- 団塊の世代（1947〜49年生まれ）が2025年に後期高齢者（75歳以上）へ一斉移行完了（いわゆる「2025年問題」）
- 要介護・要支援認定者数：約700万人超（2025年度推計）、今後10年で800〜900万人へ拡大見込み
- 85歳以上人口が急増フェーズ：認知症・身体介護需要の質的変化を伴う

**介護報酬改定サイクル**
- 2024年4月：直近の介護報酬改定（全体では+1.59%、処遇改善加算拡充）
- 次回改定：2027年4月予定（診療報酬との同時改定）。介護職員の賃上げ・外国人材拡充・テクノロジー活用加算が焦点と見られる
- 2027年改定は施設系・在宅系問わず事業者収益の分岐点となり得る

**介護人材不足（ミクロ・マクロ共鳴テーマ）**
- 2030年には約60万人規模の介護人材不足と厚労省試算
- 在留資格「特定技能2号」（介護）の本格稼働により外国人介護人材市場が拡大
- 人材紹介・派遣、SaaS、ロボティクス各セグメントへの波及

**サブセクター整理**
| サブセクター | 主要テーマ | 代表銘柄 |
|---|---|---|
| 在宅介護・デイサービス | 規模拡大、稼働率管理 | チャーム・ケア、シダー |
| 施設介護（有料老人ホーム） | 開設コスト回収、稼働率 | チャーム・ケア、アズパートナーズ、サンウェルズ |
| 介護人材紹介・派遣 | 需給ひっ迫による単価上昇 | エス・エム・エス、ライク |

| 介護用品・CSセット | 施設数増加に連動 | エラン、フランスベッドHD、日本ケアサプライ |
| 高齢者向け食事・生活支援 | 高齢者単身世帯増 | シルバーライフ |
| 高齢者向けホスピス・看取り | 死亡数ピーク（2040年代） | 日本ホスピスHD |

| 介護ロボット | 省人化需要、HAL | CYBERDYNE |

## 5. 個別Growth-Screen分析

> **分析フレームワーク:** マクロ要因（高齢者人口増加・構造的需要）と ミクロα（市場シェア拡大・単価上昇・競合優位）を分離して評価。介護報酬改定（2027年次回）を潜在的なインフレクションポイントとして評価。

---

### 5-1. エス・エム・エス（2175）プライム

**事業概要:** 介護・医療・グローバル領域の人材紹介・メディア・SaaSを展開。国内介護人材紹介最大手の「カイゴジョブ」を運営。ケアマネジャー向け業務支援ツール「ケアマネドットコム」も保有。

**マクロ要因:**
- 介護離職・人材不足が深刻化する中、民間人材紹介市場は需要逼迫が続く
- 要介護者増加 → 介護事業所増加 → 人材採用需要増加の連鎖

**ミクロα:**
- 「カイゴジョブ」は国内最大規模の介護求人メディア。データ蓄積によるマッチング精度向上がスイッチコスト創出
- 医療・グローバル（フィリピン・インドネシア等）での多角展開がリスク分散かつ外国人介護人材台頭への先行対応
- SaaS型「ケアマネドットコム」は低解約・定額収入で安定収益基盤

**2027年改定インパクト:**
- 介護報酬改定で処遇改善加算が拡充されるほど、事業所の採用意欲が高まる → 掲載件数・紹介報酬収入の増加
- 外国人介護人材拡充施策は同社のグローバル事業と直接連動

**財務評価:** FY2025 3Q売上高473億円（ペース）、PER 20.7倍。高ROE水準を維持。配当・自社株買いも実施。

**リスク:** 景況悪化時の求人減少（ただし介護は景気非感応性が高い）、競合プラットフォームの台頭（インディードなど）

**総合評価:** ★★★★★（マクロ・ミクロ共に強い。人材紹介大手として最も安定した成長株）

### 5-2. エラン（6099）プライム

**事業概要:** 介護施設入居者向け「CSセット（Care Support Set）」サービス。衣類・タオルの洗濯付きレンタルと日用品・おむつのパッケージ提供。全国の特別養護老人ホーム・有料老人ホーム等に展開。

**マクロ要因:**
- 施設介護入所者数は高齢者増加とともに構造的に拡大
- 施設新設ペースの継続 → CSセット新規契約の積み上がり

**ミクロα:**
- CSセット市場のデファクトスタンダード（競合参入障壁：施設との長期関係・システム統合）
- 既存施設契約更新に伴う単価上昇余地。施設数増加でなくても既存施設の居室数拡大・入居率向上で売上増
- 二桁増益ペースを維持（予想経常利益増益率19.5%）

**2027年改定インパクト:**
- 施設介護の報酬改定は施設新設・改装を促す → CSセット需要の追い風
- 処遇改善加算拡充は施設の受け入れ拡大意欲を高める

**財務評価:** 時価総額435億円、PER 13.6倍（予）、自己資本比率55.1%、配当利回り2.23%。低PERで成長率と不一致（PEGが割安）。

**リスク:** 特定施設種別への集中、おむつ原材料費高騰、施設建設コスト上昇による新設鈍化

**総合評価:** ★★★★★（低PER×二桁成長のギャップが最大の魅力。施設数増加という不変の需要ドライバー）

### 5-3. カナミックネットワーク（3939）グロース

**事業概要:** 医療・介護・子育て支援分野向けSaaS。自治体・医師会・介護事業者が患者・要介護者情報をリアルタイム共有できる「情報共有プラットフォーム」と、ケアマネ・介護事業者の業務効率化「介護業務管理システム」の2層構造。

**マクロ要因:**
- 介護DXは国策：国が地域包括ケアシステム構築のIT化を推進
- 地域医療情報連携ネットワークの整備加速

**ミクロα:**
- 14期連続増益（FY2026 2Q: 売上+17.8%、営業利益+30.9%）
- SaaS型で解約率が極めて低い（自治体・医師会ネットワークへの組み込みで事実上ロックイン）
- 2026年からAI課金（新機能）開始 → ARPUアップサイド
- 「Kanamic Vision 2035」で次の10年成長戦略を明示

**2027年改定インパクト:**
- 介護報酬改定でデジタル化推進加算・テクノロジー活用加算が拡充見込み → カナミックのシステム導入インセンティブが増す
- 自治体予算に介護DX費用が計上されやすい環境

**財務評価:** 時価総額201億円、PER 18.0倍（予）。グロース市場でこの規模ながら黒字・高利益率。PEG＜1.0で成長に比して割安。

**リスク:** 顧客集中（自治体・医師会）、競合の大手IT企業参入、AI課金の顧客浸透ペース

**総合評価:** ★★★★★（SaaSの低解約モデル＋AI課金開始でARPU拡大。2027年改定の直接受益者）

### 5-4. チャーム・ケア・コーポレーション（6062）プライム

**事業概要:** 有料老人ホーム「チャーム」ブランドで関西・東京圏を中心に展開。開設地域別価格設定に特徴。

**マクロ要因:**
- 有料老人ホーム需要は高齢者増加に伴い継続拡大
- 関西圏は高齢化率が特に高く、地域密着型の優位性あり

**ミクロα:**
- FY2026 3Q: 売上高339億円（+11.8%）、営業利益36億円（+43.9%）と大幅増益
- 稼働率向上と新規開設が利益成長を牽引
- ブランド認知度向上による入居者獲得コスト低減

**2027年改定インパクト:**
- 施設介護の報酬単価改定は直接収益に影響。プラス改定なら利益率が大幅に改善
- 開設コスト（建設費・採用費）は先行費用。改定後の単価上昇が回収を加速

**財務評価:** 推定時価総額230億円前後、営業利益成長率+43.9%は高い。ただし有利子負債水準に注意要。

**リスク:** 施設開設の先行投資コスト、人件費上昇、施設稼働率の初期低迷リスク

**総合評価:** ★★★★（施設拡張フェーズの高成長。ただし財務レバレッジへの注意が必要）

### 5-5. 日本ケアサプライ（2393）スタンダード

**事業概要:** 福祉用具レンタル卸の最大手。三菱商事・ALSOK（綜合警備保障）が大株主。居宅介護支援事業者向けに車いす・歩行器・介護ベッド等を卸・販売。

**マクロ要因:**
- 在宅介護推進政策（施設から在宅へ）が追い風
- 要介護者増加 → 福祉用具レンタル需要増加（制度で自己負担1割）

**ミクロα:**
- FY2026 通期予想上方修正：売上高350億円、営業利益31.5億円（+29.9%）
- 三菱商事バックアップの信頼性・商流での優位
- 物流ネットワーク整備による配送コスト効率化

**2027年改定インパクト:**
- 福祉用具の貸与・購入基準の見直しが懸念材料（一部品目の購入義務化論議）だが、実際の影響は限定的との見方が多い
- 在宅介護推進施策継続なら需要は拡大

**財務評価:** 時価総額338億円、売上高350億円（ほぼ等倍）。営業利益率約9%（改善傾向）。PBR・配当データは安定。

**リスク:** 福祉用具貸与ルール見直しリスク（購入義務化）、物流コスト高止まり

**総合評価:** ★★★（安定配当・大手資本バックの守備的成長株。大きな上値は限られるが安全性高い）

### 5-6. フランスベッドHD（7840）プライム

**事業概要:** 介護用ベッドのトップブランド「フランスベッド」。介護用品レンタル・販売の他、医療用マットレス、エアコン・家具等の複合事業。

**マクロ要因:**
- 介護ベッドは要介護者増加に伴いレンタル需要が拡大
- 施設・在宅双方への供給基盤

**ミクロα:**
- ブランド力（「フランスベッド」は介護ベッドの代名詞）による価格支配力
- レンタルの継続課金モデルで解約率が低く安定収益
- FY2025 3Q売上高448億円（累計）

**2027年改定インパクト:**
- 在宅介護推進政策は介護ベッドレンタル需要に直接寄与
- テクノロジー活用（見守りベッドセンサー等）への投資が報酬加算に連動する可能性

**財務評価:** 時価総額439億円、PER 14〜16倍、PBR 1.1倍、配当利回り3.27%。バリュー株的水準。

**リスク:** 成長率は緩やか（3〜5%レンジ）、高齢者人口増加の恩恵を受けるが上値限定的

**総合評価:** ★★★（高配当・安定ブランド。キャピタルゲイン狙いより配当インカムで評価）

### 5-7. ライク（2462）プライム
