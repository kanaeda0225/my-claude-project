# ライク (2462) 外国人材就労支援サービス 売上規模 推定 (2026-05-17)

## 1. 結論サマリー

- **推定売上 (FY2025/5 実績ベース): 約 1.5 - 5 億円 (中央値 ~3 億円)**
- **推定全社売上比率: 約 0.2 - 0.8 % (中央値 ~0.5%)**
- **確度: ★★☆☆☆ (5段階中2)**
  - 直接開示が皆無のため、ピア類推 (WillGroup) + 介護分野シェア top-down + 登録支援機関規模感の3手法で triangulation
  - 上限・下限の幅が広い (約3倍) のは、ライクが「登録支援機関業務 (B2C/B2B生活サポート)」中心か、「人材紹介・派遣」中心か、によって単価モデルが大きく変わるため
- **主要な前提と感度:**
  - 最も感度が高いのは「受託人数」: ライクは公開数値を出していないため、介護分野シェアと従業員数からの推定 (300-1,000 名レンジ) が結論を支配
  - 「ライクスタッフィングが特定技能の支援業務 (月額3万) のみ提供」か「紹介料 (5-100万/人) も計上」かで売上が2-3倍ぶれる
- **核心インサイト:** 中計27/5期の「新たな取組み 94億円」は、建設業界向け人材+障がい者就労+外国人材 の **3事業合算**。外国人材単独では 30-50億円程度が想定上限と推定され、現状はそのうち5-10%しか到達していない可能性。「成長軸」位置付けと実態に**かなりのギャップ**がある。

### セグメント内での外国人材の位置付け

- ライクスタッフィング (連結子会社) が主体で、「総合人材サービス事業」の中に **派遣・紹介ビジネス**として、「新たな取組み」の中に **登録支援機関 (生活サポート)** が並走して計上されている可能性が高い (会社の説明も不明瞭)。
- ライクケア (介護子会社) も独自に特定技能外国人を**自社雇用**しており、これは「介護関連サービス事業」の人件費側に計上 (= 外国人材就労支援事業の売上ではない)。

## 4. 三角測量による推定

### 4.1 Top-down 推定 (介護分野シェア)

| 項目 | 数値 | 出典 |
|---|---:|---|
| 介護分野 特定技能在留者数 (2024/12末) | 44,367 人 | 出入国在留管理庁 |
| 介護分野 特定技能在留者数 (2025/6末) | 54,916 人 | 出入国在留管理庁 |
| 全国 登録支援機関 数 | 1万社超 (大半は中小) | 法務省 |
| ライクの想定シェア (介護のみ) | 0.5 - 2% | 介護で1.5万人を上位50社が分け合うと仮定 |
| **ライクが介護分野で支援する人数 (推定)** | **250 - 1,100 人** | |
| 月額生活サポート費 (WillGroup単価) | 3 万円 | WillGroup IR |
| **年間サポート収入 (介護分野)** | **0.9 - 4 億円** | |
| 人材紹介料 (1人当たり) | 50 - 80 万円 (初年度のみ) | 業界相場 |
| 新規流入比率 (年率) | 20-30% | 業界平均 |
| **年間紹介収入 (介護分野)** | **0.3 - 2.5 億円** | |
| **介護分野 売上推定 計** | **1.2 - 6.5 億円** | |

これに介護以外 (建設・宿泊・外食・製造) を加味すると、ライクは介護に強みを持つ会社のため、介護以外のシェアは介護より小さいと想定し、**全分野で 1.5 - 8 億円**。

### 4.2 Bottom-up 推定 (社内活用 × 規模感)

| 項目 | 数値 | 仮説 |
|---|---:|---|
| ライクケア介護スタッフ数 | ~1,000 名 | 公式情報 (25施設, 定員1,500名+) |
| 介護スタッフのうち外国人比率 | 5 - 10% | 業界平均よりやや高い設定 (グループ施策有) |
| ライクケアの外国人介護スタッフ数 | 50 - 100 人 | |
| 外部介護事業者への紹介・支援人数 (Like Staffing) | 200 - 500 人 | 自社の3-5倍を外部紹介と仮定 |
| 介護以外への支援人数 | 100 - 300 人 | 建設・製造・宿泊 |
| **合計受託人数 (推定)** | **350 - 900 人** | |
| 1人当たり年間売上 (サポート+紹介按分) | 30 - 60 万円 | ピア類推 |
| **売上推定** | **1.0 - 5.4 億円** | |

### 4.3 ピア類推 (vs ウィルグループ)

| 指標 | WillGroup (6089) | ライク (2462) | 倍率 |
|---|---:|---:|---:|
| 連結売上高 | 1,400 億円 (24/3) | 623 億 (25/5) | 0.45x |
| 外国人材セグメント開示 | あり ("外国人管理受託") | **なし** | - |
| 受託人数 (24/3末) | **2,341 名** | n/a (推定 300-1,000) | 0.13-0.43x |
| 受託人数 (26/3末計画) | 3,500 名 | n/a | - |
| 外国人材売上規模 | **約 10 億円** (3,500名フル稼働時) | 推定 1.5-5 億 | **0.15-0.50x** |
| 月額単価 (生活サポート) | 3 万円 | 同等と推定 | - |

**含意:**
- WillGroupが連結売上の **0.7%** を外国人材で稼ぐのに対し、ライクは現状 **0.2-0.8%** と推定 — つまり**ピア比でやや劣後**しているか、せいぜい同等。
- WillGroupは「製造業」で大量採用に強みを持つビジネスモデル (派遣の延長線)。ライクは介護中心で、介護は **EPA・在留資格バリエーション多数 (技能実習・特定技能・EPA・育成就労)** で1社当たりの集積が起きにくく、規模拡大が構造的に難しい。

## 5. 推定値レンジ

| シナリオ | 売上 (FY2025/5) | 全社比 | 主要前提 |
|---|---:|---:|---|
| **下限** | **1.5 億円** | **0.2%** | 受託人数 ~300人、生活サポート費中心、紹介料は最低限。実質「Like Care 自社雇用 + 少量の外部紹介」フェーズ |
| **中央値** | **3.0 億円** | **0.5%** | 受託人数 ~500人、サポート+紹介ミックス。介護分野で WillGroup の25-30% 規模 |
| **上限** | **5.0 億円** | **0.8%** | 受託人数 ~900人、紹介料込みの全方位サービス。WillGroup の半分程度の規模 |

(参考) FY2027/5 中計の「新たな取組み 94億円」の内訳推定:
- 建設業界向け人材: 40-55 億円 (建設派遣はライク既存ノウハウ活用、最も伸びやすい)
- 障がい者就労支援 (ライクチャレンジサポート): 10-15 億円
- 外国人材就労支援: **30-40 億円** (=現状の **6-25 倍** の拡大が必要)

→ **外国人材で27/5期に30億円を達成するためには、年率50%以上の高成長**が必要。現状の進捗ペースでは未達リスクが高い。

## 6. 投資判断への含意

### 6.1 「成長軸」位置付けと実態のギャップ

- ライクは中計策定時 (2022年) から「外国人材就労支援サービス」を3つの新規成長事業の一つに位置付けているが、**FY2022→FY2025の3年間で具体的な数値開示が一切ない**。これは投資家への透明性として大きな問題。
- 中計27/5期の「新たな取組み94億円」のうち外国人材が **30-40億円** だとすれば、現状推定 1.5-5億円から **6-25倍の拡大**を3年で実現する必要がある。**極めて挑戦的**。
- 競合 (WillGroup) は数値開示・送り出し機関ネットワーク・専門子会社 (ウィルオブ・ワーク) を持ち、ライクより数歩先行。**ライクは「言ってるだけ」のリスクが高い**。

### 6.2 WillGroup比較でのαの見え方

- WillGroup: 売上1,400億、外国人材 10億円規模 (0.7%) → 受託人数3,500名計画は明示
- ライク: 売上623億、外国人材 推定 1.5-5億 (0.2-0.8%) → 受託人数非開示
- **同じ「外国人材プレイ」テーマで両社を比較する場合、ピュアプレイ度合いはWillGroup>>ライク**
- ライクの投資妙味は、外国人材ではなく **子育て支援 (53%) と介護関連 (12%) の本業安定+ M&A余地** にあると評価すべき
- 「外国人材」を投資テーマにライクを選ぶのは、**現状の数値根拠としては薄弱**

### 6.3 今後のモニタリング指標 (検証可能性)

検証のためにモニターすべき開示:
1. **決算説明資料での「新たな取組み」の内訳開示** (建設/障がい者/外国人材の3区分での売上数値)
2. **登録支援機関としての受託人数** (年次開示があれば)
3. **送り出し機関との提携プレスリリース** (現地パートナー獲得の有無)
4. **日本語学校・教育機関のM&A** (バリューチェーン拡大の指標)
5. **介護分野特定技能受け入れ施設数** (ライクケア自社+外部受託)
6. **業績予想修正で「新たな取組み」セグメントが個別言及されるか**

特に注目: 2027/5期中計の最終年度に向け、2026/5期(進行期)の通期決算 (2026年7月予想) で「新たな取組み」の数値内訳が出るかどうか。出なければ中計未達リスクは大幅上昇。

## 7. 限界・残課題

### 7.1 1次情報の未取得部分

- **ライクの有価証券報告書 PDF 全文** — 本調査ではWebFetchが403で取得できず。注記事項・セグメント情報の詳細未確認。
- **決算説明資料** (各四半期) — Webアクセス制限により全資料の精査ができず。「新たな取組み」のセグメント内訳が個別資料で言及されているか未確認。
- **出入国在留管理庁の登録支援機関一覧 PDFデータ** — 個社の支援人数の開示はないため、ここで止まる。

### 7.2 開示で確定できない部分

- **ライクの受託人数の絶対値** (WillGroupのように開示しない限り推定値止まり)
- **「総合人材サービス」内と「新たな取組み」内で外国人材売上がどう分割されているか**
- **介護分野特定技能の介護施設別シェア (厚労省統計でも企業単位の開示なし)**

### 7.3 推定の感度

- 月額生活サポート費を3万円→2万円に変更すると売上推定は **33%減**
- 受託人数を中央値500人→1000人に変更すると売上推定は **2倍**
- 紹介料のカウント方法 (年初一括 vs 按分) で **±30%**

### 7.4 補足としての見方

ライクの「外国人材就労支援」は、現時点では **数値的にマテリアルではない (全社売上の1%未満)** が、子育て・介護の本業に対する **オプション・将来オプティオン**として位置付けるのが妥当。中計達成余地ではなく、業績モメンタムドライバーとしてのインパクトは限定的。
