## 0️⃣ 発表サマリー

### 一言で言うと

**創業後の成功にあぐらをかき、25年間も保守的な経営に甘んじてきたワンマン社長が、AIや競合の出現による環境激変に危機感を覚え、本気の成長フェーズに突入する話。コンサル特化の転職エージェントとして、自社プラットフォームで集客し、キャリアアドバイザー（CA）がさばく仕組み。CA増員・クライアントシフト・SEO強化・過去DB掘り起こしの4施策が一斉に効きはじめ、3年で売上は2,387 → 10,647百万円（×4.5倍）、純利益は575 → 4,908百万円（×8.5倍）。市場は「市場に比例して伸びる会社」と見ているが、実態は内部施策による加速フェーズ。**

---

### 成長を因数分解する

ムービンの売上は経験年数コホート別に分解できる。

```
売上 = 1年目CA人数 × 一人当たり売上 
     + 2年目CA人数 × 一人当たり売上
     + 3年目以降CA人数 × 一人当たり売上

別の見方（検算用）：
売上 = 成約数 × 成約単価
成約単価 = 転職後の年収 × 手数料率
```

| 因数 | 方向 | なぜ動くか |
| :---- | :---- | :---- |
| **1年目CA人数** | ↑ 今期+35、来期+40、再来期+40 | 採用計画。手取金をCA人件費に充当 |
| **2年目以降CA人数** | ↑ コホートで自動的に厚くなる | 定着率1年目92.11%、2年目以降81.82% |
| **一人当たり売上** | ↑ 入社1年目→2年目で4.7倍、3年目で7.99倍 | 経験曲線。新規採用は即戦力にならない |
| **成約単価** | ↑ 1.00 → 1.49（3年で+49%） | 年収+5%/年（インフレ+人手不足）× 手数料率35→40%+ |

**核心の結論**：ムービンの売上爆発は「市場の伸び（10%）に比例」では絶対に説明できない。**CAという律速段階が解消された直後**で、しかも単価も同時に上がる二重の追い風がある。だから市場の伸びを大きくoutperformする。

---

### なぜ市場が気づいていないか

| 観点 | 現状 |
| :---- | :---- |
| 過去の業績 | 2025年に入るまでほとんど伸びていない（25年間ヨコヨコ）→ 市場は「成長しない会社」と認識 |
| 直近の伸びの解釈 | 「コンサル市場の伸びに比例して成長する会社」と見られる |
| 実態 | **施策起因の加速フェーズ**。CAという律速が外れ、施策効果が積み上がっている |
| 来期以降 | 4施策はまだ途上段階。**直近の変化は一過性ではなく、むしろ加速する** |

市場は「市場のCAGR10%」の倍率でムービンを評価しがちだが、実際は内部要因で**売上×4.5倍、純利益×8.5倍**のスピードで成長する。このギャップがミスプライシングを生んでいる。

## 2️⃣ マクロ：市場の追い風

### 全体の流れを先に把握する

```
【今起きていること】
コンサル業界 年率約10%成長（IT・DX・PMOが牽引）
   × 業界の人手不足（求人倍率8.68倍 vs 全国平均2.51倍）
   × インフレ+人手不足による年収+5%/年成長

【ムービンへの影響】
求人数 ↑ × 年収 ↑ × 手数料率 ↑ → 成約数と成約単価が両方上がる
```

---

### 2-1. コンサル業界の市場拡大

- 年率**約10%成長**
- 特に**ITコンサル、DX支援、PMO**が伸びている
- 要因：生成AIを活用した新事業開発、DX・IT刷新のニーズの高まり
- 見通し：潮流は変わらず**中長期的に高成長**を続ける

### 2-2. コンサル業界の人手不足

**他業界より3倍以上人手不足**：

| 指標 | コンサル | 全国平均 |
| :---- | :---- | :---- |
| 転職求人倍率 | **8.68倍** | 2.51倍 |

要因：
- **需要**：前述のコンサル市場規模の成長
- **供給**：少子高齢化による転職者の採用需要の増加、雇用流動化の加速
- **固有**：新陳代謝が前提の企業風土とそれに伴う離職率の高さ

→ 構造的なものであるため、**中長期的に人手不足は続く**

### 2-3. インフレによる年収上昇

- 2022年から年率2%でインフレが発生
- IMFによると少なくとも2030年まで年率2%でインフレ
- **インフレ + 人手不足で年率5%で年収上昇**

→ 構造的なものであるため、**中長期的に年収上昇**

### 2-4. マクロまとめ

```
コンサル業界が人手不足とインフレで苦しめば苦しむほど、
求人数と年収は上昇するため、
ムービンの成約数と成約単価は上昇する
```

→ ただしこれが「市場の認識：ムービンは市場の成長に比例して成長する」の根拠でもある。

**しかしムービンの実態は、市場の伸び以上の加速フェーズに入っている**——次のミクロで詳説する。

## 3️⃣ ミクロ：なぜムービンが市場をoutperformするのか

### 3-1. 歴史：25年保守経営からの大転換

#### 創業

**余命宣告されて、家族を養うために28年前に創業**——ストーリーの起点はここ。

#### 25年に渡る保守的な経営

- 長らく成長を指向しない会社で、今いる少数のメンバーが高い果実を得られればいいよね、という考えだった
- SEO対策も創業（＝インターネット黎明期）からしていて、集客は十分できていたものの**人が足りなくて、手が回っていない状態が続いていた**
- → **25年間くらい売上はヨコヨコ**

集客は実はずっと回っていた。だが、CAが足りないので案件をさばききれない——これが25年続いた構造。

#### 変曲点と危機感

外部環境が急激に変わった：

- **AIの出現**により競争環境がガラッと変わりそう
- **ビズリーチやリクルート**といよいよ競合することになった
- 創業25年で**メンバーも高齢化、そろそろ事業承継**しないといけない

→ これまでの経営方針では潰れてしまうと危機感を覚え、**スケールさせて大きいサイズの会社になるように成長に舵を切った**

#### IPOの理由

- 事業承継するには、内部統制して、資本の問題解決して... → **これならIPOと変わらない！**
- BtoCだから、今後スケールを大きくしていくには、上場して知名度を上げて、資本力があって投資ができる環境が必要不可欠
- → IPOがこの解決策として合理的

#### 社長の想い

- 社長はムービンのことを子供みたいに思っているらしい
- 子供の終わりが微妙なのは忍びないから最後まで立派に送り出したい
- 家族も大株主→自分が死んでも食わせてあげたい？
- 家族を養うために創業したのにも筋が通っている
- **まだ社長が死ぬ予定はない**（重要）

---

### 3-2. 4つの施策——いま一斉に効き始めている

#### 施策① SEO対策の強化

**2022年にSEO対策のメンバーを増量**：

| 年 | 自社HP経由の集客 |
| :---- | :---- |
| 2022年 | 4,200人 |
| 2023年 | 4,600人 |
| 2024年 | **5,800人** |

→ 自社HP経由の集客が確実に増えている

#### 施策② キャリアアドバイザー増員

- これまではデータベースに求職者が貯まっていくのを処理できていなかった
- **2024年以降CAの採用数を増やした**
- 彼らが戦力になるのは**来期以降**

→ いま採用しているCAの成果はまだ業績に反映されていない。これが「加速フェーズ」の根拠。

#### 施策③ クライアントシフト

**積極採用している企業に多く送客**：

- 2024年1Qからクライアントのポートフォリオを入れ替え
- 先述の伸びているクライアントからの募集をキャッチしてフォローアップ
- 4Qから徐々に成果が出始めるが**まだ途上**

#### 施策④ 過去データベースの掘り起こし

**過去に支援した求職者を再び支援**：

- それまでは一度支援したら終わりだった
- 2023年から掘り起こしを開始
- 成果が出たため増員
- **2割しかアプローチできていない → まだ余地あり**

---

#### 4施策のまとめ

```
保守的経営だったのが、外部環境の変化をきっかけとして、

① SEO対策による集客力強化
② キャリアアドバイザー増強によるボトルネック解消
③ クライアントシフトによる成約単価・成約数上昇
④ 過去データベース掘り起こしによる成約数上昇

にのりだした

この成果はまだ途上段階であり、来期以降に実を結ぶ
→ 直近の変化は一過性ではなく、むしろ加速フェーズである
```

---

### 3-3. 競合優位性

#### 求職者サイド：SEO対策 ＆ 扱っているコンサル求人情報数 No.1

- SEO対策により広告を除いてムービンのHPが一番上に出てくる
- 創業から長い & 扱っている求人数が一番多い（IR電話）ため、そのまま選ばれる
- 実績：**広告費0で前期は5,800人以上自社HPから集客**

#### クライアントサイド：良い在庫がいっぱい揃っている

- クライアントは良い在庫をいっぱい送ってくれる転職エージェントが好き
- ムービンは集客数が多い & 高学歴が多い
- → クライアントに好まれやすい！
- 特に積極採用のクライアントに関しては、**彼らの予定人数分送客している**
- → 今後さらに関係が良くなる

#### CAサイド：年収が高い

- 採用力として一番分かりやすい年収がめちゃめちゃ高い
- 自社PFで集客できているため、余計な広告宣伝費をかけなくても良く、その分をこちらに回せている

### 3-4. 参入障壁

```
他社が同じことをやろうとすると：
   ↓
集客力の強いプラットフォームを持っていない
   ↓
他社プラットフォーム利用料をたくさん払わないといけない
   ↓
過去のデータベースもないので、新規集客に依存
   ↓
多量の広告宣伝費を使わないといけない
   ↓
年収にお金が回せず、採用力が落ちる
   ↓
良いCAが採れず、案件処理能力が落ちる
```

**集客力の強いプラットフォームや過去データベースは短期では獲得不可能**であり、**創業28年の蓄積が参入障壁**になっている。

## 5️⃣ Appendix

---

### A. キャリアアドバイザー数の根拠

**今期+35人、来期+40人、再来期+40人採用予定**：

- 手取金（IPO調達資金）はCAの人件費に充当する予定
- IR電話によると、上記の採用計画を立てている
- 良い在庫さえあればCAの仕事は簡単であり、ムービンの採用力も高いため、**この採用計画は難なく達成しそう**

---

### B. 一人当たり売上高の根拠

**新規採用から即戦力になるためには時間を要する**：

- 目論見書によると、入社1年目対比の平均売上高は入社2年目で**4.7倍**、入社3年目で**7.99倍**
- これを元に計算すると入社1年目の平均売上高は**900万円**
- 入社年数ごとの増加は「一人当たり成約数」によるもので、今後これは一定だと仮定する
- → 一人当たり売上高は**成約単価の増加に比例**する

---

### C. 成約単価の根拠

**成約単価 = 転職後の年収 × 手数料率**

#### 転職後の年収

インフレ（+2%）と人手不足の合算で**年率5%成長**と仮定

#### 手数料率

- **クライアントシフト前**：35%（業界平均と同じくらい）
- **クライアントシフト後**：手数料の高いクライアントへの送客数が増えたことで**最低40%**はある（IR）
- 今後は履歴書の増加に伴って、積極採用の企業に送り込める人材が増えるため**さらに上昇する見込み**

---

### D. 成約数の構造

- 自社PF経由が**81%**、外部PF経由が**19%**
- 自社PFのうち80%が新規、20%が過去データベースからの掘り起こし

#### CAボトルネックの程度

**新規履歴書数の5.7%しか現状送客できていない**

→ 新規履歴書数の**6〜7分の1**まではいけそう（つまり伸びしろ大）

#### 今後の構造

- IRによると、自社新規集客：自社DB掘り起こし：外部新規集客の比率は維持できる想定
- しかし、**過去DB掘り起こしにはそろそろ限度がありそう**なのでここを横ばいと仮定
- その分を**外部集客に頼るパターン**でバリュエーション

---

### E. 外部集客について

#### 現状は広告宣伝費0

- 他社PFから引っ張ってくる方が安い（IR）
- 他社PF利用料は**固定費はほぼ0で、変動費である成功報酬がメイン**

#### 今後の方針

- CA数が律速段階だったため、外部集客を強化しようとしていなかった
- **費用対効果がよければ広告も全然考えている**
