### 成長を因数分解する

売上高、粗利ともに「新規 + 既存（リニューアル）」の2セグメントで分解する。

```
売上高 = 新規案件売上 + リニューアル売上

粗利 = 新規案件売上 × 新規粗利率
     + リニューアル売上 × リニューアル粗利率
```

| 因数 | 方向 | なぜ動くか |
| :---- | :---- | :---- |
| **新規案件売上** | ↑ +10%/年 | マクロ需要に連動。電設サブコン各社の単価+5〜10%上昇 |
| **リニューアル売上** | ↑ +15%/年 | マクロ+10% に加えて、営業注力による追加+5% |
| **新規粗利率** | ↑ 30 → 36 → 39 → 42% | ★★ 顧客の電設サブコン業績改善で値上げが通る |
| **リニューアル粗利率** | ↑ 40 → 46 → 49 → 52% | ★★ 新規よりも構造的に10pt高い + 値上げ |
| **販管費率** | 22 → 24%（横ばい） | 直近の業績動向も見ながら24%でおいた |

**核心の結論**：かわでんは「**値上げ × ミックスシフト**」の二重のレバレッジが効く。リニューアルの方が10pt粗利率が高く、かつ伸び率も+15%でリニューアルの方が高い——つまり時間が経つほど自動的に全社の粗利率が上がる構造。営業利益は 1,135 → 7,111百万円（**×6.3倍**）。

### 商品紹介：配電盤・分電盤とは

- **配電盤**：電力会社からの高圧の電気を、ビル内で使えるよう低圧に変成する装置
- **分電盤**：ブレーカーのこと

つまり「**建物の電気の入り口**」。建設には必須の機器。

---

### カスタム品と汎用品の違い

| 用途 | 製品 |
| :---- | :---- |
| 一般戸建住宅、中小マンション、ビル | **汎用品**で事足りる |
| 高層ビル、データセンター、半導体工場、その他一般工場 | **カスタム品**が必須 |

理由：上記の建物は電力消費量が多く、建物の構造も複雑で汎用品では対応できない。

- **カスタム品を作っている上場会社は日本ではかわでんしかない**
- 競合がカスタム品市場に進出するのは難しい（Appendix参照）

### A. 投資期間：いつ売るか

#### 投資期間について

- **29年期4Qから新工場建設に伴う減価償却費と費用が掛かってくる**、毎年数十億円規模のものになるので29年期の営利はそれほど伸びない（かわでんIR）
- **値上げによる利益率改善が続くと現時点で断言できるのが2〜3年後まで**（関電工IR）

→ よって、新工場に関する費用が掛かる前にいったん売却するのが資金効率的には最善と判断する。

#### 推奨売却タイミング

- **2027年5月**：28年期のガイダンスが出る時点
- もしくは**2028年2月**：28年期3Qの決算が出る時点

これが最も効率がいい。

### B. 社員数の前提（採用と離職）

- 新卒で毎年30人、中途で毎年10〜20人採用していく方針、採用活動は順調に推移していて今年は50人くらい取れるめどがついている（IR）
- 離職率に関しては毎年20人強でここ数年推移しており、社員の年齢層を見てもここ数年間はこれくらいの数字で落ち着きそう（IR）
- **毎年の採用者数を40人、離職人数を25人と仮定して社員数を計算**（過去2〜3年の社員数の推移を見ても、平均して毎年15人は増えているのでそれほど違和感ない数字）

### C. そんなに採用できるのか？ → できる

- この会社については採用ペルソナが完全に電設サブコンと被るわけではないが、参考として電設サブコン最大手の**きんでんは400人、関電工は300人**ほど採用
- **ターゲットとなる人材は毎年3,000〜8,000人くらいいる**（関電工IR）
- ここ数年新規、中途合わせて毎年40〜50人の採用はできている（IR）
- 同業他社と比較しても給料はそこまでかわらない、この会社だけ人数が極端に来ないことは考えにくい

---

### D. きんでんや関電工などの大手に人手を吸われてしまうのか？ → 可能性は低い

- 関電工やきんでんなどの大手は採用を絞っている
- 人を取りすぎるといつか工事需要が減った際に大規模リストラをせざるを得なくなる。関電工やきんでんは**バブル期にそれをやって、今中間職の不足に苦しんでいるトラウマ**で大規模な採用には踏み切らない
- 関電工は年300人、きんでんは年400人ほどの採用をしているが、**採用倍率は関電工が約10倍、きんでんは20倍近く**
- → そこで落ちた人たちがこの会社などに来る
- 大手の採用倍率の話から潜在的な新卒の採用候補は**数千人単位**でいる
- 競合他社以上の給料は出している（IR）

---

### E. 1人当たり売上高について

- 上記の社員数をもとに1人当たり全社売上高とリニューアル事業売上高を算出できる
- 具体的に何人が新規に、何人がリニューアルに分けられているかの区分はなく、**新規とリニューアルの人員の移動は割と流動的に起こりやすい**（IR）
- 全社員数から1人当たり全社売上高とリニューアル事業売上高を算出するしかないのだが、毎年5〜10%の値上げが通ることを考えると、出てきた1人当たり売上高はそれほど違和感ない数字
- 体感としてここ数年の稼働率は一定で推移してきた感覚があり、**現状リニューアルがキャパってる感覚はない**（IR）

---

### F. リニューアル事業は他社に代替されてしまうのでは？ → されない

- この会社は**汎用品ではなくカスタム品**を作っているため、製品の顧客リストや設計図はこの会社しか持っておらず、この会社特注や独自の部品も多く使われている、それらは他社は調達できない（IR）
- 仮に古くなったこの会社の商品を捨てて他社の商品に切り替えようと思っても、**建物自体の電気システムがすでにこの会社の配電盤に合うように作られている**わけだから、配電盤を変えようとすると建物全体の電気システムを変える必要がある。それほどの手間とコストを客がかけるメリットはない
- **既存顧客のメンテナンスや修理、交換需要はほぼすべてかわでんでさばいている**（IR）

---

### G. 競合やもっと安い外国企業の台頭の可能性は？ → 低い

- 配電盤はただ量産品を工場で作ればいいというものではなく、**一つ一つの現場に合わせてカスタム品を工場で作る**
- 汎用品を売っている会社がカスタム品に参入しようとしても、カスタム品を設計する人材や設備をすぐには整えられず、しばらくはかわでんの一強が続く
- 外国企業が日本でカスタム配電盤を売ろうとしても**販売、設置する作業人員や体制をすぐには確保できない**
- 顧客も電気工事の要である配電盤を信用のない会社にいきなり任せるとは考えにくい

---

### H. 他の企業を買ったらいいのでは？ → かわでんが最適

- 関電工、きんでんなどの全国の案件を手掛ける超大手は**PERの時点でアップサイドがこの会社より限られる**
- この会社は様々な会社と取引があり、全国の優良案件に携われる。どこか一地方の案件しかできない地方電設サブコンを買うよりかは、**この会社を買ったほうが全国のおいしい案件を全て取れる**
- **カスタムの配電盤を大規模に作れるのはここだけ**で、配電盤は電気工事に必要不可欠なので、立場的にはこの会社のほうが上
- 日本国内でDC向けの製品の需要を独占しているのはここだけ
