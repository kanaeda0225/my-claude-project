# 系統工事業界 体系プライマー

> 投資判断の前提知識として系統工事業界の構造・テーマ・制度・用語を体系化したもの。
> 銘柄一覧は `_sector-grid-construction-japan.md` を参照。

---

## 1️⃣ 業界の前提構造

### 1-1. 「系統」とは何か

電気を作って届けるネットワーク全体のこと。3層構造:

```
[発電所] ─── 送電網 ─── 変電所 ─── 配電網 ─── [需要家]
              ↑              ↑           ↑
            66〜500kV     電圧変換     6.6kV→100/200V
            超高圧         (昇圧/降圧)   低圧
```

| 階層 | 電圧 | 設備 | 工事の担い手 |
| :---- | :---- | :---- | :---- |
| 送電 | 66kV〜500kV | 送電鉄塔・架空線・地中ケーブル・海底ケーブル | 旧電力系工事会社+鉄塔/送電線専業(A) |
| 変電 | (変換) | 変電所・GIS・大型変圧器 | 旧電力系工事会社+重電(B-1)+中堅機器(B-2) |
| 配電 | 6.6kV以下 | 配電線・柱上変圧器・配電盤 | 旧電力系工事会社+配電盤(B-3)+配電機器(B-2) |

### 1-2. 2020年の発送電分離 ─ なぜ「一般送配電事業者」が出てくるのか

2020年4月の電力システム改革で、旧電力会社(東電・関電など)は機能ごとに分社された:

| 旧東京電力(HD) | 機能 | 新会社 |
| :---- | :---- | :---- |
| → | 発電 | 東京電力フュエル&パワー |
| → | **送配電(系統運用)** | **東京電力パワーグリッド (TEPCO PG)** |
| → | 小売 | 東京電力エナジーパートナー |

→ 系統工事を発注するのは **「一般送配電事業者」(=送配電子会社)** の方。
→ つまり 1942 関電工の発注主は **東京電力PG** であって東京電力HDではない、ということ。

### 1-3. 系統工事の発注フロー

```
① 一般送配電事業者                 (発注元)
   (東京電力PG / 関西電力送配電 / 中部電力PG ほか旧9社)
        ↓ 直接発注
② 電力系総合電気工事会社                (元請け)
   (1942関電工 / 1944きんでん / 1959九電工 / 1946トーエネック ほか)
        ↓ 二次外注 + 機器調達
③ 専業施工会社                      (鉄塔/送電線/配電線/電車線)
   (1921巴コーポ / 5915駒井 / 1938日本リーテック ほか)
        ↓ 機器発注
④ 重電・送変電機器メーカー
   (6501日立Energy / 6508明電舎 / 6617東光高岳 / 6648かわでん ほか)
        ↓ 素材調達
⑤ 電線・ケーブルメーカー
   (5801古河 / 5802住友電工 / 5803フジクラ / 5805SWCC ほか)
```

> ポイント: **②の元請けがほぼ「系列発注」になっている** ことが日本特有の構造。
> TEPCO PG発注の80%以上は関電工+東京エネシス(両社ともTEPCO系列)が取る、というのが慣行。

### 1-4. なぜこのモデルなのか(=歴史)

- 1951年: 戦後の電気事業再編成で日本を9電力エリアに分割(沖縄含めて10)
- 各電力会社が **設備工事と保守を行う子会社** を設立 → これが現在の電力系工事会社
- 70年間で **「現場の地理 + 図面 + 設備履歴 + 作業員」** が系列の中に蓄積された
- 競争入札を導入しても、これらの知見を持つ系列会社が結局勝つ → 系列発注が温存

## 2️⃣ いま業界に効いている5つの追い風

### テーマ1: マスタープラン2023(系統増強 6〜7兆円)

#### 正式名称
**「広域系統長期方針」** — 電力広域的運営推進機関(OCCTO)が2023年3月公表

#### 背景となる課題
1. 再エネ豊富な地域(北海道・東北・九州)と需要地(首都圏・関西)が遠い
2. 既存連系線の容量が不足 → **系統制約** で発電出力を抑制せざるを得ない
3. 東西で周波数が違う(50Hz/60Hz)→ 周波数変換装置(FC)経由でしか融通できない
4. 1960〜70年代設計の老朽インフラ

#### 主要プロジェクト

| プロジェクト | 概要 | 想定運用開始 |
| :---- | :---- | :---- |
| 新北本連系線 (HVDC) | 北海道〜東北日本海側 海底直流送電線 | 2030年代前半 |
| 常磐幹線 | 東北→東京の送電容量増強 | 2030年代 |
| 東西連系線 | 周波数変換装置(FC)を 210万kW → 300万kW へ拡張 | 2027年運開済予定一部 |
| 中国〜九州連系線 | 九州の余剰再エネ送り出し | 2030年代 |
| 関門連系線 | 本州〜九州 増強 | 2030年代 |

#### 鉄塔発注ピークの仕組み

```
2024 ─ 計画詳細化・環境アセス
2025 ─ ルート確定・用地交渉
2026 ─ 設計完了・鉄塔発注スタート ←──┐
2027 ─ 鉄塔発注ピーク年              │ ここが
2028 ─ 鉄塔製作+一部建設            │ 鉄塔メーカー
2029 ─ 鉄塔建設ピーク                 │ 受注ピーク
2030 ─ 主要回線運用開始               ←──┘
```

鉄塔は注文から建つまで3〜5年かかる → 2030年運用開始のためには2026〜30年が発注ピーク。

#### 投資への含意
- 鉄塔メーカーは **1921 巴コーポレーション**・**5915 駒井ハルテック** の2強 → 寡占恩恵
- 海底ケーブルは **5801 古河・5802 住友電工・5803 フジクラ** の3強(世界寡占)
- HVDC変換所は **6501 日立(Hitachi Energy)** が世界シェア上位
- 電力系工事会社(C)は全社が二次受益

### テーマ2: 再生可能エネルギーの大量導入

#### 国の目標
- 2030年: 再エネ比率 36〜38%(現状は約20%)
- 2050年: カーボンニュートラル → 再エネ50〜60%

#### 中でも洋上風力
- 政府目標: 2030年までに10GW、2040年までに30〜45GW
- ラウンド1(2021年): 三菱商事3海域全勝で議論を呼んだ
- ラウンド2(2023年): 5海域、コンソーシアム多様化
- ラウンド3(2024年〜): 浮体式含む新海域

#### 系統工事への波及
- 洋上風力は主に **秋田・千葉・北海道** に集中
- これらから需要地まで送るには **陸側の系統増強(連系工事)+ 海底ケーブル** が必要
- 直接受益:
  - 海底ケーブル: 古河・住友・フジクラ
  - 洋上風力タワー: **5915 駒井ハルテック**・**5911 横河ブリッジHD**
  - 海洋土木+ケーブル敷設艀: **1893 五洋建設**
  - 陸側連系工事: **1832 北海電気工事**・**1934 ユアテック**

#### 直近の論点
- 2024年: 三菱商事が落札済3海域の建設を一時凍結検討 → 業界に逆風
- 2025年: 入札制度見直し(FIT価格上方修正)で再活性化期待

### テーマ3: データセンター/半導体ファブの新増設

#### 電力需要の爆発
- 国内データセンター電力需要: 2023年 約20TWh → 2030年 50TWh+ → 2050年 100TWh+
- 1サイトあたりの消費電力が **10倍化** している(従来30MW → 新規300MW級)
- 受変電設備の規模・複雑性も比例して拡大

#### 主要立地と地理的偏在

| 地域 | 案件 | 受益銘柄 |
| :---- | :---- | :---- |
| **北海道(石狩・千歳)** | ラピダス IIM-1(2nm半導体) + 大規模DC群 | 1832 北海電気工事 |
| **東北(北上・宮城)** | キオクシア北上・東北DC | 1934 ユアテック |
| **関東(印西・外房・相模原)** | DC新増設の最大集積地 | 1942 関電工 / 1949 住友電設 |
| **中部** | TSMC関連サプライチェーン | 1946 トーエネック |
| **関西(京阪奈・神戸・大阪南港)** | 西日本DC集積 | 1944 きんでん |
| **熊本(菊陽町)** | TSMC JASM 第1・第2工場 | **1959 九電工** |

#### 設備工事のボトルネック
- 案件数 ≫ 工事会社のキャパシティ → 受注単価が上昇中
- 専門電気工事士の不足が深刻 → 工期遅延の常態化
- **受注単価+粗利率の同時上昇** が起きており、これが業界の構造変化(まさに 6648 かわでん ピッチの2-4の話)

#### 機器側への波及
- 受変電盤: **6648 かわでん**(カスタム品)・**6651 日東工業**(汎用品)
- UPS: **6516 山洋電気**
- 変圧器・GIS: **6508 明電舎**・**6617 東光高岳**
- 構内空調: **1969 高砂熱学**・**1980 ダイダン**

### テーマ4: 原発再稼働

#### 経緯
- 2011年: 福島第一事故で全機停止
- 2013年〜: 新規制基準に基づき審査
- 2015年: 川内原発再稼働(九電)が皮切り
- 現在稼働中: 関電(高浜3・4、大飯3・4、美浜3)、九電(玄海3・4、川内1・2)、四国(伊方3)
- **2024年12月: 柏崎刈羽(東電)の運転認可問題が解消方向 → 7号機再稼働へ**

#### 系統工事への波及
- 原発稼働再開には:
  1. 発電所内の機械据付・整備工事(タービン・冷却系)
  2. 送電線・変電設備の点検・更新
  3. 系統側の調整工事(原発出力は調整不可なので、調整力が他で必要)

#### 中核プレーヤー
- 発電所工事: **1968 太平電業**(発電所機械据付の専業)
- 重電: 日立・東芝・三菱重工(蒸気タービン・原子炉)
- 系統側: 各電力系工事会社

### テーマ5: 老朽インフラ更新サイクル

#### 数字で見る老朽化
- 鉄塔: 全国約24万基。設計寿命70年。1960〜70年代設置がピーク → **2030〜40年に更新ピーク**
- 配電用柱上変圧器: 全国約670万台。寿命40〜50年。1970〜80年代設置 → **既に更新ピーク入り**
- 地中送電線(管路): 1970〜80年代が中心 → 2020〜30年代に更新
- 配電盤・受変電設備(ビル内): 1970〜90年代の建物用 → **更新需要が爆発的に増加中**

#### 投資への含意
- 受益銘柄は時期ごとに違う:
  - 既ピーク中: **6623 愛知電機**(柱上トランス)・**6648 かわでん**(配電盤リニューアル)
  - これからピーク: **1921 巴コーポレーション**(鉄塔)・地中送電線各社
- これは **当面消えない構造的需要**(発注主が更新を止めると停電する)

## 3️⃣ 系統工事の経済性 ─ なぜ今、利益率が上がるのか

### 3-1. 受注単価の上昇
- 工事会社は需要過多で **値上げ交渉力** を持ち始めた
- 過去: コスト+α の薄利請負(電力会社の言い値)
- 現在: 「人手が足りないのでこの単価でないと請けません」と言える

### 3-2. レベニューキャップ制度(2023年導入)
- 一般送配電事業者の収入を5年間固定する制度
- 設備投資をしっかりすると規制上のリターンが約束される
- → 一般送配電事業者が **積極投資にシフト**(従来は投資抑制)
- → 工事会社の受注パイ拡大

### 3-3. 専門電気工事士の不足
- 電気工事士(第一種)資格保有者の高齢化(60代以上が4割)
- 若手参入が少なく、頭数が増えない
- → 工事の **キャパシティ自体が制約に**
- 結果として工事会社は案件を選べる立場に

### 3-4. リニューアル比率の上昇による利益率改善
- 新設工事より既設リニューアルのほうが粗利率が高い
  - 新設: ゼネコン経由で発注され、競争入札 → 粗利率10%前後
  - リニューアル: 既導入先への直接営業 → 粗利率20%以上
- ストック型ビジネスに近い性質
- 例: 6648 かわでん は新規:リニューアル = 7:3 を 5:5 にシフト中

## 4️⃣ 重要用語集

### 系統設備
| 用語 | 説明 |
| :---- | :---- |
| 送電線 | 一般に66kV以上の高圧電線。275kV/500kVが基幹 |
| 配電線 | 6.6kV以下、需要家まで届ける低圧電線 |
| 鉄塔 | 送電線を支える鋼構造物。高さ20〜100m級 |
| 変電所 | 電圧変換と系統切り替えを行う施設 |
| 柱上変圧器 | 電信柱の上にある小型トランス(6.6kV→200V) |
| 配電盤 | 受電した電力を分配・制御する盤 |
| 受変電設備 | ビル/工場が高圧を受けて低圧化する設備一式 |

### 機器
| 用語 | 説明 |
| :---- | :---- |
| **GIS** | Gas Insulated Switchgear。ガス絶縁開閉装置。変電所のコア |
| **HVDC** | High Voltage Direct Current。高圧直流送電。長距離・海底に適する |
| **FC** | Frequency Converter。50/60Hz周波数変換装置 |
| **PCS** | Power Conditioning System。直流-交流変換(太陽光・蓄電池) |
| **BESS** | Battery Energy Storage System。系統用蓄電池 |
| **SVC/STATCOM** | 系統電圧を瞬時に調整する装置 |
| **OPGW** | Optical Ground Wire。光ファイバー入り架空地線 |
| **碍子(がいし)** | 鉄塔と送電線の間の絶縁体。陶器製 |
| **UPS** | Uninterruptible Power Supply。無停電電源装置 |

### 制度・市場
| 用語 | 説明 |
| :---- | :---- |
| **OCCTO** | 電力広域的運営推進機関。系統運用の司令塔 |
| **FIT/FIP** | 再エネ固定価格買取/プレミアム制度 |
| **容量市場** | 4年後の発電能力(kW)を取引する市場 |
| **需給調整市場** | 短時間の調整力(kW)を取引する市場 |
| **ノンファーム型接続** | 系統に空きがある時間だけ送電を認める制度(2021年〜) |
| **レベニューキャップ** | 一般送配電事業者の収入を5年間固定する制度(2023年〜) |
| **N-1基準** | 系統内の1要素が故障しても停電しない設計基準 |
| **系統制約** | 送電容量不足で発電を抑制せざるを得ない状態 |
| **出力抑制(再エネ抑制)** | 再エネを発電できるのに送れず止める措置 |

### プレーヤー区分
| 用語 | 説明 |
| :---- | :---- |
| **一般送配電事業者** | 旧電力の送配電子会社。系統運用と工事発注の主体 |
| **発電事業者** | 旧電力の発電子会社+IPP+再エネ事業者 |
| **小売電気事業者** | 旧電力の小売子会社+新電力 |
| **電力系工事会社** | 旧電力の系列工事会社(関電工・きんでん など) |

## 5️⃣ 投資を考えるときに見るべき指標

### 5-1. 個別企業
1. **受注残高 / 売上比**: 1.0倍を超えると「将来1年分以上の仕事を確保」=好調
2. **粗利率の推移**: DC・更新需要で **改善トレンド** に入っているか
3. **官公庁(電力)発注比率 vs 民間比率**: 民間比率が上がると粗利改善方向
4. **海外売上比率**: グローバル系統増強で米欧売上が伸びるか(大型のみ)
5. **設備投資/減価償却比**: 工事キャパシティの拡張意欲

### 5-2. マクロ指標
1. **電力10社の設備投資計画**: 各社IRで公表される5カ年計画
2. **OCCTO 系統増強の進捗**: ルート確定・着工タイミング
3. **電気工事業の月次受注金額**(国交省「建設工事受注動態統計」)
4. **電気工事士有効求人倍率**: 高止まりだと単価上昇継続

### 5-3. リスク・逆風シナリオ
- 政権交代で再エネ目標が下方修正される
- 半導体・DC投資の世界的減速
- 鋼材・銅価格の高騰で粗利圧迫
- レベニューキャップ見直しで電力側の投資が抑制方向に戻る
- 大規模な工事事故・労災で安全規制強化

## 補遺: 「電力系」「電力系工事会社」と何度も出てくる理由

日本の系統工事業界を理解するうえで、**旧一般電気事業者(=旧電力9社)** の存在は決定的。

| 旧電力 | 一般送配電子会社 | 系列工事会社(主要) |
| :---- | :---- | :---- |
| 北海道電力 | 北海道電力ネットワーク | **1832 北海電気工事** |
