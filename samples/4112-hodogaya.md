## 0️⃣ 発表サマリー

### 一言で言うと

**Appleが2026年のMacBook Proに初めてOLEDを採用する。そのパネルを作るのはSamsung Displayで、Samsung DisplayにOLED材料を供給するのがSFC——保土谷化学が50%出資する合弁会社だ。ノートPCという大画面デバイスへのOLED拡大は、スマホ向けとは比べ物にならない材料需要を生む。アナリスト0社のこの銘柄は、まだ機関投資家に発見されていない。**

---

### 成長を因数分解する

保土谷化学の収益成長は、以下の4つの積として表せる。

SFCへの材料需要 ∝ IT-OLEDパネルの枚数 × 画面の面積 × 発光層の積層数 × (1/歩留まり)

このうち「IT-OLED市場全体の成長（CAGR 37%、Omdia）」はパネルの枚数しか捉えていない。面積と積層数という2つの追加乗数がかかるため、SFCへの材料需要は市場平均の成長を大幅に上回ると考える。

| 因数 | 方向 | なぜ動くか |
| :---- | :---- | :---- |
| **IT-OLEDパネルの枚数** | ↑ CAGR 37% | MacBook Pro、iPad Proの普及 |
| **画面の面積** | ↑ スマホ比 約25倍 | スマホ→ノートPCへの移行。面積が増えると材料も増える |
| **発光層の積層数（タンデム）** | ↑ \+50〜75% | ノートPC用OLEDは発光層を2層重ねる構造が標準 |
| **(1/歩留まり)** | ← 改善中 | A6ライン歩留まりが85%超に到達。安定フェーズへ |

**核心の結論**：MacBook Pro 1台分のOLED材料需要 ≈ iPhone換算 約11〜14台分。200万台出荷はスマホ換算2,200〜2,800万台分の材料需要を意味する。

**PBRとは**：会社の純資産（解散したときに株主に戻ってくる価値）に対して、株価が何倍かを示す指標。0.69倍は「今すぐ解散しても株価より多くお金が戻ってくる」状態で、割安のサインとして使われる。

### ビジネスモデルの全体像

表面上は「化学メーカー」だが、収益の柱はSFCへの持分法利益である。

保土谷化学工業（4112）

│

├─ 国内化成品事業（染料・農薬中間体など）

│    → 安定的だが成熟。成長ドライバーではない

│

└─ SFC（Samsung Fine Chemicals）＊　← 投資テーゼの核心

     → 保有持分: 約50%

     → 韓国法人。Samsung Display（SDC）と50:50の合弁

     → 主力製品: 青色OLEDホスト材料・ドーパント

     → 主要顧客: Samsung Display（ほぼ独占的）

＊SFCの利益が増えると、保有割合に応じて保土谷化学の連結利益に「持分法利益」として計上される（連結子会社ではなく持分法適用会社）。

**この発表で重要なのは**：保土谷化学の業績はSFCのOLED材料需要と連動する。SFCへの需要が爆発すれば、保土谷化学の利益は急拡大する。

---

### 「SFC」と「OLED材料」を理解する

**そもそもOLEDとは**

OLEDとは有機ELディスプレイのこと。液晶（LCD）と違い、有機化合物の薄膜に電気を流すと自ら光る仕組み。薄くて美しい発色が特徴で、iPhoneやSamsung Galaxyのスマホに使われている。

**OLEDの構造（超簡略版）**

\[陰極（−）\]

  ↑ 電子が流れてくる

\[電子輸送層\]

┌────────────────────────────────┐

│ 発光層（EML）                    │

│  ・青色ホスト材料 ← SFCが供給  │  ここで光が生まれる

│  ・青色ドーパント（発光体）      │

└────────────────────────────────┘

\[正孔輸送層\]

  ↑ 正孔が流れてくる

\[陽極（+）\]

**青色ホスト材料とは何か（アナロジー）**

「ホスト」とはコンサート会場（ホスト）と演者（ドーパント）の関係に例えられる。演者（発光体）がどれだけ輝けるかは、会場の音響・照明・広さ（ホスト材料の品質）で決まる。どんな優れた演者でも、粗末な会場では実力を発揮できない。青色ホスト材料はOLEDの発光効率と寿命を決める「会場」だ。

**なぜ青色が難しいか**

RGBの三色のうち、青色（Blue）が最も技術的に難しく、材料コストも高い。青色発光体は劣化しやすく、発光効率も赤・緑より低い。OLEDの画質・寿命は「青の品質」で決まると言っても過言ではない。SFCはこの最難関の材料を専門とする。

## 2️⃣ マクロ：「MacBook ProのOLED化」が引き起こす材料需要の構造変化

### 全体の流れを先に把握する

【今起きていること】

スマホOLED市場は成熟・縮小 → でも代わりにノートPC・タブレット向けOLEDが急拡大

【2026年の最大イベント】

Apple MacBook ProにOLEDが初採用 → Samsung DisplayのA6ラインが量産開始

【なぜ材料需要が「スマホの時代」とは桁違いか】

大画面 × 発光層2枚（タンデム構造） → 1台あたりの材料量がスマホの11〜14倍

---

### 2-1. スマホからIT機器へ：OLEDの主戦場が変わった

OLEDはiPhoneを皮切りにスマホに普及したが、そのスマホ市場は今や飽和しつつある。

| セグメント | 2026年成長率 | 状況 |
| :---- | :---- | :---- |
| スマホOLED材料 | **\-3%** | 市場飽和。単価も低下 |
| タブレットOLEDパネル | **\+39%** | iPad Pro、Galaxy Tab等 |
| ノートPCOLEDパネル | **\+46%** | MacBook Pro OLEDが牽引 |
| OLEDモニター | **\+61%** | ゲーミング・クリエイター向け |

出典：Omdia（2025〜2026年データ）

**つまり**：OLED材料市場全体の平均成長率で保土谷化学を評価するのは間違い。スマホOLEDの縮小に引きずられず、急成長するIT-OLED分野に保土谷/SFCの事業は集中している。

---

### 2-2. 2026年の最大カタリスト：MacBook Pro OLED量産開始

Appleは2026年にMacBook Pro（14インチ・16インチ）に初めてOLEDを採用する。

**なぜこれが「歴史的な転換点」か**：

- これまでAppleのMacBookはすべて液晶（LCD）だった  
- OLEDは液晶より製造コストが高いが、薄さ・画質・省電力で圧倒的に優れる  
- Appleがノートパソコンにもオールインするということは「OLEDが本格的にPC市場に普及し始めた」というシグナル

**製造側の状況（Samsung Display A6ライン）**

| 項目 | 内容 |
| :---- | :---- |
| 製造会社 | Samsung Display（韓国、サムスン電子の子会社） |
| 工場・ライン | 天安工場 A6ライン（第8.6世代ガラス基板） |
| 量産開始 | 2026年5〜6月にガラス投入開始、7月本格量産 |
| 歩留まり | 4月下旬時点で85%超（Digitimes報道）。目標の90%に迫る |
| Apple向け出荷目標 | **200万枚（2026年中）** |
| 競合の状況 | Samsung Displayがリジッド8.6G OLEDを独占供給。BOEはフレキシブル基板対応で技術的に別物 |

**歩留まり（ゆどまり）とは**：製造した製品のうち、品質基準を満たしたものの割合。85%なら100枚作って85枚が合格品ということ。85%超は量産フェーズとして十分なレベル。

---

### 2-3. タンデムOLED：「発光層2枚重ね」が材料消費を倍増させる

ここが「材料需要が単純な台数増以上に伸びる」最大の理由。

**タンデムOLEDとは**：従来のOLEDは発光層が1枚（シングルスタック）だが、ノートPC・タブレット向けでは発光層を2枚重ねる「タンデム（Tandem）構造」が採用される。

【従来のスマホ向けOLED（シングルスタック）】

    \[発光層 × 1枚\]  ← 材料を1枚分だけ使う

【ノートPC向けOLED（タンデム構造）】

    \[発光層 × 1枚\]

    \[電荷生成層\]    ← 2層を繋ぐ層

    \[発光層 × 1枚\]  ← 合計で材料を2枚分使う

**なぜノートPCはタンデムが必要か**： ノートPCは長時間使われ、かつスマホより画面が大きいため輝度と寿命の要求が高い。タンデム構造にすることで各発光層の負荷を半分に抑えられ、寿命が大幅に伸びる。スマホのOLEDパネルをそのまま大きくしてもノートPCの要求水準を満たせないため、タンデムが事実上の必須構造となっている。

**タンデム採用率の推移**

| 時期 | 採用率 | イベント |
| :---- | :---- | :---- |
| 2023年以前 | 約0% | IT向けOLEDはほぼ存在しない |
| 2024年 | **30%超** | iPad Pro（史上初のタンデムOLED製品）が登場 |
| 2026年（予測） | **36%** | MacBook Pro OLEDが加わる |

出典：Omdia（2025年4月）

タンデム採用率が上がるほど、パネル枚数以上のペースで材料消費が増える。採用率が0%から36%に増えただけでなく、今後も上昇が見込まれる。

---

### 2-4. まとめ：なぜ材料需要が「市場平均成長率を大幅に超える」か

ここまでを整理する。

OLED材料市場全体のCAGR予測（主要調査機関）

  ├─ 18.8%（IMARC Group）

  ├─ 22.5%（Market Research Future）

  └─ 37.0%（Omdia、モバイルPC向け）

※ 一部のレポートが引用するQYResearch（5.4%）は

  旧来のスマホOLED材料のみを対象にした可能性が高く、

  IT-OLEDの急拡大を織り込んでいない。

SFCの材料需要成長（試算）

  \= IT-OLEDの台数成長（+37%）

    × 面積効果（スマホ比 約25倍）※一時的な水準切り上げ

    × タンデム係数（+50〜75%）

  → 材料消費量ベースのCAGR：推定 45〜65%

**MacBook Pro 1台とiPhone 1台の材料消費の違い**（直感的な理解のために）

| 比較項目 | iPhone（スマホ） | MacBook Pro 16インチ |
| :---- | :---- | :---- |
| 画面面積 | 約135 cm² | 約3,400 cm²（約25倍） |
| OLED構造 | シングルスタック | タンデム（2層） |
| 材料消費量（換算） | 1台分 | **約11〜14台分** |

MacBook Pro 200万台の出荷 \= スマホ換算で約2,200〜2,800万台分の材料需要が生まれる。

## 3️⃣ ミクロ：なぜSFCが、その需要を独占できるのか

マクロでIT-OLED材料の需要が急拡大することは分かった。次の問いは「なぜSFCがその恩恵を取りこぼさないか」だ。

---

### 3-1. SFCの競争優位性（Moat）：3つの参入障壁

**① 資本的な一体化（最重要）**

Samsung Display（SDC）はSFCの共同出資者である（SDCと保土谷化学が約50:50）。

Samsung Display ─── 50%出資 ─→ SFC ←─ 50%出資 ─── 保土谷化学

                                 ↑

                         「自分が株主の会社」

                         から材料を買っている

競合材料メーカーへの切り替えは「自分が株主の会社を外す」という意思決定を意味する。SDCがSFCを切り替えるインセンティブは構造的にほぼゼロ。

**類比**：コンビニのオーナー（SDC）が、自分が出資しているサプライヤー（SFC）を切り捨てて他のサプライヤーに変えるか？よほどの品質問題でもなければしない。

---

**② 昇華精製技術の暗黙知（技術的参入障壁）**

OLEDホスト材料は**不純物が1ppm（100万分の1）以下**という超高純度が求められる。

この純度を実現するための「昇華精製」というプロセスは：

- 温度・圧力・速度の微妙な調整が必要  
- 最適なパラメータを見つけるには数年〜数十年の試行錯誤が要る  
- 技術者の「勘」に依存する部分が多く、マニュアル化・移転が困難

保土谷化学は1878年創業の有機化学メーカーで、SFCにその技術が移転されている。後から参入した競合が同じ品質を出すのは極めて難しい。

---

**③ スペックインサイクルの長さ（時間的参入障壁）**

OLEDパネルメーカーが材料を切り替えるには以下のプロセスが必要：

新材料の評価開始

  → 単体特性評価（発光効率・色・電流効率）    ： 数ヶ月

  → デバイス評価（パネルレベルでの寿命・画質） ： 数ヶ月〜1年

  → 量産試験（歩留まり・安定性の確認）         ： 数ヶ月

  → 量産ラインへの組み込み

                              合計：最短でも 2〜3年

一度SFCの材料がSamsung DisplayのA6ラインに組み込まれたら、競合が同品質の代替品を開発できても、すぐには切り替えられない。**スペックインされた材料は2〜3年間、構造的に保護される。**

---

### 3-2. 「今が変曲点」であることの確認

2024年 → iPad Pro Tandem OLED採用（タンデム採用率が0%→30%超に急上昇）

2026年Q2 → Samsung Display A6ライン稼働・MacBook Pro向け材料出荷開始  ← 今ここ

2026年Q3 → MacBook Pro発売（Apple秋イベント前後）

2026年Q4 → SFCへの材料需要がピーク。業績への反映が始まる

2027年以降 → iPad Air OLED・MacBook Air OLEDなど追加案件が続く見込み

重要なのは、これは「MacBook Proだけの一発イベント」ではないという点だ。MacBook ProはAppleがOLEDをPC市場全体に展開していく第一歩に過ぎない。IT-OLEDという新しい市場カテゴリーが立ち上がる構造的な転換点の始まりである。

---

### 3-3. なぜSFCはマクロをoutperformするか（まとめ）

| 理由 | 詳細 |
| :---- | :---- |
| 顧客がSDCに集中している | SDCはIT-OLED（MacBook Pro）の独占サプライヤー。SDCの生産量増加がそのままSFCの需要増に直結する |
| スマホOLED縮小の影響を受けない | SFCの主用途はIT-OLED。スマホ市場の縮小がSFCの業績を引き下げない |
| タンデム採用率上昇の恩恵 | 採用率が上がるほど1枚あたりの材料消費が増える。タンデムの波及は続く |

**試算（参考）**

IT-OLED台数成長（CAGR）       ： \+37%（Omdia）

タンデム採用率上昇の追加効果 ： \+3〜5%（2024→2026）

基板面積増大（6G→8.6G）       ： \+10〜15%（一時的）

─────────────────────────────

SFCの材料消費量推計CAGR       ： 45〜65%（保守〜楽観シナリオ）

### なぜまだ割安なのか

保土谷化学のPBRが0.69倍という低水準にある理由は、市場が同社を依然として「成熟した染料・化学メーカー」と見ているからだ。SFCの青色ホスト材料がMacBook Pro向けに量産出荷されるという事実が、利益予測に織り込まれていない。

さらにSFC自身がKOSPI（韓国証券取引所）への上場を計画しており、実現すれば保土谷が保有するSFC持分の価値が市場で可視化される。現在は簿価（取得原価ベース）でしか見えていない「隠れた資産」が表面化する可能性がある。

## 5️⃣ Appendix

---

### A. LG Chem vs. SFC 特許訴訟リスク（最重要テールリスク）

**本筋（メインストーリー）とは別に、株価を大きく動かしうるリスクとして記載する。**

#### 概要

韓国の化学大手LG Chemが、SFCの主力製品（青色OLEDホスト材料）が自社の特許を侵害しているとして訴訟を起こしている。判決が出るのが2026年7〜8月——MacBook ProのOLED量産開始と完全に重なるタイミングであることが最大の問題。

#### 訴訟の経緯

| 時期 | 出来事 |
| :---- | :---- |
| 2019年 | LG Chem、米DuPontから青色ホスト材料の特許を買収。直後にSFCを提訴 |
| 2022年 | 韓国特許審判院、SFCの「特許無効」申立を棄却（LG Chem側が勝訴） |
| 2024年 | 特許法院でも再度SFCが敗訴。**SFCは2審で2連敗** |
| 2026年4月2日 | 別件で、最高裁がSFCの別の特許を有効と判断（SFCにとってポジティブな先例） |
| 2026年4月16日 | LG Chem、訴状を更新。損害賠償に加え**製造・販売・輸入禁止＋在庫廃棄**を追加請求 |
| **2026年7〜8月** | **最高裁が最終判断を下す予定** |

#### LG Chemの請求内容

| 請求 | 規模 |
| :---- | :---- |
| 損害賠償 | 約300億ウォン（約22億円）。SFCの年間利益と同規模 |
| 製造・販売・輸入禁止 | SFCの青色ホスト材料の製造・販売・輸入をすべて差し止める |
| 在庫廃棄 | 現在の在庫をすべて廃棄させる（韓国では極めてまれな請求） |

#### シナリオ分析

| シナリオ | 推定確率 | 保土谷株への影響 |
| :---- | :---- | :---- |
| **A. 和解 or SFC勝訴** | 40% | ✅ 訴訟リスク消滅。メインストーリーが純粋に機能 |
| **B. 損害賠償のみで決着** | 45% | ⚠️ 約22億円の特別損失。供給は継続。株価への影響は軽微 |
| **C. 製造差し止め命令** | 15% | ❌ MacBook Pro量産タイミングで供給停止。テーゼ崩壊。株価-30〜-50%リスク |

#### なぜシナリオCの確率が低いか

1. **Samsung Displayが全力で阻止する**：SDCはSFCの共同出資者であり、自社の量産ラインに直結する材料が止まることは許容できない。SDCがLG Chemとクロスライセンス交渉に入る動機が極めて強い。  
2. **韓国の司法慣行**：特許侵害訴訟での即時製造差し止めは極めてまれ。損害賠償が主な救済手段となることが多い。

#### 投資家として注目するチェックポイント

- **2026年5月の本決算発表**：有価証券報告書の「偶発債務」脚注に訴訟への言及が増えているか  
- **The Elec等の韓国メディア**：SDCとLG Chemの水面下の交渉観測記事  
- **2026年7〜8月の判決テキスト**：特許有効でも、判決の「射程（どの分子構造まで対象か）」次第でSFCは継続供給できる

### C. SFC KOSPI IPO計画（追加カタリスト）

OLED-info（2025年11月）の報道によれば、SFCはKOSPI（韓国証券取引所）への株式上場を計画中。

**なぜ保土谷化学の株価に影響するか**：

- 現在、保土谷のバランスシートにあるSFC持分は「取得原価（簿価）」で計上されている  
- SFCが上場すると、SFC株に市場価格がつき、保土谷の持分が「時価」で評価される  
- PBR 0.69倍という「割安」の主因である「簿価に埋もれたSFC価値」が表面化する

**リスク**：LG Chem訴訟の結果によってはIPO計画が延期・中止となる可能性がある。

### E. BOEによる追加機会（参考情報・不確実）

BOEは成都に第8.6世代OLEDラインを建設中（2025〜2026年）。将来的にSFCが材料を供給する可能性がある。

ただし：

- BOEのラインはフレキシブルOLED（ポリイミド基板）対応で、MacBook Pro向けのリジッドOLED（ガラス基板）とは別の技術  
- SFCがBOEに採用されている確認ずみのエビデンスは現時点でない  
- 2026年中の高品質量産はスケジュール的に難しい

**評価**：メインストーリーに組み込まず、オプション価値として保持。
