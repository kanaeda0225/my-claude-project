## 0️⃣ 発表サマリー

### 一言で言うと

**メックはパッケージ基板の銅箔向け薬剤（密着向上剤＝CZシリーズ）を製造販売しており、その市場を独占している。GPU向けのパッケージ基板は通常基板に比べて層数が2〜3倍・面積が10〜15倍、しかも今後2年でさらに面積が2倍になる。1枚あたりの薬剤消費量は「面積×層数」の積で増えるため、CZ向け需要はGPU出荷台数の伸びを大きく上回って爆発する。これにより1年で純利益は1.4倍、株価は1.6倍になる。よってBUY！！！**

---

### 成長を因数分解する

CZシリーズの売上は以下のように2段で分解できる。

```
CZ売上 = 汎用（スマホ・パソコン）向け + GPU用PKG向け

GPU用PKG向け = 前年売上 × GPU生産伸び × 面積増加率 × 層数増加率 × 使用量補正
```

このうち「GPU出荷台数の成長」だけ追っても、面積と層数の累乗効果を捉えきれない。だからGPU出荷台数の伸びの何倍ものスピードで材料需要が伸びる。

| 因数 | 方向 | なぜ動くか |
| :---- | :---- | :---- |
| **GPU生産伸び（基板生産数YoY）** | ↑ 30/20/10%（25-27年） | AIサーバー需要。電力制約での鈍化を保守的に織り込み |
| **銅箔面積（mm²）** | ↑ Hopper 4,000 → Blackwell 7,500 → Rubin 12,000 | ★★★ NVIDIA世代交代で大判化が止まらない |
| **銅箔層数** | ↑ Hopper 12 → Blackwell 14 → Rubin 18 | ★★ 信号・電源密度の上昇でz方向に多層化 |
| **使用量補正** | 50%固定 | GPU向けは多層化のため極限まで薄く粗化（汎用の半分） |
| **汎用向け** | 横ばい（CAGR 0%として保守） | バリュエーションでは伸びを織り込まない |

**核心の結論**：CZ売上は 24/12 12,699百万円 → 27/12 22,039百万円（**+74%**）。このうちGPU向けに絞れば **37,375百万円 → 155,152百万円（+315%）** という爆発的な伸び。GPU生産数自体は1→1.72（×1.72）にしかならないのに、薬剤消費量は4倍以上に膨らむ——これが「面積×層数」の累乗効果のインパクト。

## 1️⃣ 基本情報

### 会社の概要

**株式会社メック（東証プライム：4971）**

| 項目 | 内容 |
| :---- | :---- |
| 主事業 | 銅箔表面処理薬剤（密着向上剤・エッチング剤） |
| 売上構成 | **薬剤事業が99%**、機械・資材その他は1%以下 |
| 主力製品 | **CZシリーズ（密着向上剤）が薬剤の7割以上** |
| 投資期間 | 26/12通期決算発表まで（約1年） |

メックは老舗の化学薬剤メーカーで、薬剤が99%を占め、その薬剤の中でもCZシリーズという**密着向上剤**が7割以上を占める。事業構造はびっくりするほどシンプルで、「CZの売上がどうなるか」がそのまま株価のストーリーになる。

---

### CZシリーズとは

**パッケージ基板製造時に必須**の薬剤。これが無いと銅箔と樹脂の界面が剥がれて、端がめくれたりして歩留まりが悪化する。

「あっても無くてもいい添加剤」ではなく、**無いと製品ができない**という性質の薬剤であることを押さえておいてほしい。だからこそ価格交渉力が強い。

#### CZシリーズの生誕ストーリー

```
1990年代、基板の材料がセラミック → 有機樹脂に切り替わった
   ↓
「銅箔と樹脂が剥がれる」という新しい問題が浮上
   ↓
メックが銅の表面を粗化することで密着度を高める手法を提案
   ↓
その後デファクトスタンダード化した
```

つまりメックは「業界の根本的な技術問題を解決したパイオニア」であり、**規格そのものを握っているポジション**にいる。後発が同じ問題を別解法で解決しようとしても、すでに業界全体がメック仕様で動いている。

---

### 半導体パッケージ基板とは

半導体（CPU/GPU）とPCB基板（マザーボード）をつなぐ「中継機」。

```
[半導体（CPU/GPU/HBM）]
       ↑
   電源・情報のやりとり
       ↓
[半導体パッケージ基板] ← ここに CZシリーズ が使われる
       ↑
   電源・情報のやりとり
       ↓
[PCB基板（マザーボード）]
```

- パッケージ基板を作るプレイヤーは **イビデン、新光電気工業など**
- メックはこれらのプレイヤーに薬剤（密着向上剤）を販売している
- **イビデンはメックの過去IRレポートにも名前が出ていた納入先**であり、いま**生産量大幅増強を打ち出している**——つまりメックの直接的な追い風

ここがポイントで、メックは「半導体メーカー」ではなく「半導体基板メーカーの薬剤サプライヤー」。半導体景気の波そのものではなく、基板メーカーの生産量増加に連動する。

---

### 今後パッケージ基板は「大判化」と「多層化」が並行で進む

#### 大判化

HBM（メモリ部分）とSoC（ロジック部分）は数が増えていくし、それぞれが大きくなる：

```
従来：       [SoC]      [HBM×2]
                  ↓ 大判化
これから：   [SoC（大）]  [HBM×4〜8]
                  → 全体のパッケージ基板（Substrate）が大型化
```

#### 多層化

ビルドアップ層もコア層も多層化が進む：

```
[ビルドアップ層]
      ↓ もっと厚くなる
[コア層]
      ↓ もっと厚くなる
[ビルドアップ層]
```

#### なぜ多層化が必要か

- そもそもパッケージ基板は「GPU側とマザーボード側の電源や情報の中継機」
- AIサーバー向けGPUは、汎用CPU/GPUに比べて**やりとりする情報や必要とする電源が桁違いに大きくなる**
- 既にx-y方向のサイズが規格化されている以上、**z方向（縦方向）に増やしていくしかない**

つまり多層化は「やりたいからやる」ではなく「物理的にそうするしかない」必然。だから止まらない。

#### イビデンの対応

メックの過去IRに名前が出ていた納入先のイビデンが、**生産量大幅増強を打ち出している**——これは「マクロの追い風が実際に取引先で具体化している」シグナル。

## 2️⃣ マクロ：パッケージ基板の大判化・多層化が引き起こす薬剤需要の構造変化

### 全体の流れを先に把握する

```
【今起きていること】
スマホ・パソコン向け基板は成熟  →  GPU向け基板の需要が爆発

【因数の動き方】
GPU出荷台数の伸び（+30/20/10%）
   × 1枚あたり面積の伸び（×3倍：4,000→12,000mm²）
   × 1枚あたり層数の伸び（×1.5倍：12→18層）
   × 使用量補正（GPU向けは汎用の半分で固定）

【結果】
GPU向けCZ売上は 37,375百万円 → 155,152百万円（+315%！）
```

---

### 2-1. GPU向け基板生産数（YoY）

- **汎用（スマホ・パソコン）向け**：CAGR 2〜3%程度の成熟市場 → **バリュエーションではCAGR 0%とした**（保守側に倒す）
- **AI用途GPU向け**：各種レポートを参考にし、電力制約などによる成長率鈍化の可能性も織り込み、**2025〜2027でそれぞれ30%、20%、10%**

GPU生産台数の見立てとして「30/20/10」は決して強気ではなく、業界の伸び期待からむしろ抑え目に置いている。**この保守的な前提でも、面積と層数の効果で結果は爆発する**ことに注目してほしい。

---

### 2-2. 現時点の基板生産数の比率

ここがちょっと地味だけど大事。「**汎用とGPUの相対的な大きさ**」を抑えておかないと、GPUの伸びをいくら掛けてもインパクトを過小評価する。

```
生産台数/年
 ① スマホ：12.2億    ② パソコン：2.65億    ③ AIサーバー：181万

パッケージ基板数（1台あたり）
 ① スマホ：10        ② パソコン：15        ③ AIサーバー：120
```

→ 用途別のパッケージ基板生産数の比は

**汎用（スマホ・パソコン）向け：GPU向け ＝ 60：1**

24/12時点ではCZ売上12,699百万円のうち GPU向けは37,375 / 160,135 ≒ 23%。これが27/12には155,152 / 277,912 ≒ 56%にひっくり返る。**3年で主力が完全に入れ替わる**わけで、見かけの「メックの売上」はそのままでも、中身が別の会社になっていく。

---

### 2-3. 銅箔面積：GPU向けは「大判化」で爆発

#### 汎用（スマホ・パソコン）向け

- スマホ用パッケージ基板：パソコン用パッケージ基板 ＝ 4：1
- スマホ用パッケージ基板層数 ＝ 150〜200mm²
- パソコン用パッケージ基板層数 ＝ 700〜1,000mm²
- **加重平均で 310mm²**

#### GPU向け：インターポーザーだけでも大判化

| 世代 | インターポーザー面積 | 余白などを考えた仕様面積 |
| :---- | :---- | :---- |
| **Hopper** | 2,831 mm² | **4,000 mm²** |
| **Blackwell** | 4,719 mm² | **7,500 mm²** |
| **Rubin** | 7,722 mm² | **12,000 mm²** |

これは各種レポートで予想されるレンジ。**HopperからRubinまでで面積3倍**。これは単純に「画面が大きくなる」のと同じで、薬剤の消費もそのまま3倍効く。

---

### 2-4. 銅箔層数：GPU向けは「多層化」で増える

#### 汎用（スマホ・パソコン）向け

- スマホ：4 / パソコン：1 の生産比率
- スマホ：5層 / パソコン：11層
- **加重平均で 6.2層**

#### GPU向け：モルガン・スタンレーのレポートを元に置く

| 世代 | 層数 |
| :---- | :---- |
| Hopper | 12 |
| Blackwell | 14 |
| Rubin | **18** |

汎用が6.2層に対してRubinは18層、**約3倍の層数**。これも面積と同じく1枚あたり消費量に直接効く。

#### Hopper / Blackwell / Rubin の比率推移

| 年 | Hopper | Blackwell | Rubin |
| :---- | :---- | :---- | :---- |
| 24/12 | 50.0% | 50.0% | 0.0% |
| 25/12 | 20.0% | 80.0% | 0.0% |
| 26/12 | 10.0% | 70.0% | 25.0% |
| 27/12 | 5.0% | 20.0% | **75.0%** |

27/12時点ではRubinが75%を占める。**ここでもう一段、面積と層数が跳ね上がる**——だから26→27にかけて売上の伸びが加速する。

---

### 2-5. 使用量補正：GPU向けは「薄く粗化」で50%

GPU向けは多層化のために**可能な限り薄く粗化**する必要がある。製品の使い分けは以下の通り：

- 汎用向け：**CZ8101**
- GPU向け：**CZ8201**

GPU向けは汎用向けに比べて使用量は**半分（50%）**になる。

ここは保守側のファクターで、面積と層数の伸びの一部を相殺する。それでも前述の通り、最終的な売上は3年で4倍以上に膨らむ。

## 3️⃣ ミクロ：なぜメックがこの需要を独占できるのか

マクロでGPU向け薬剤需要が爆発することは分かった。次の問いは「**なぜメックがその恩恵を取りこぼさないか**」だ。

---

### 3-1. シェア：市場独占の3つの根拠

#### ① メック自身と経産省が「独占」を認めている

**メック自体や経産省も**、パッケージ基板の樹脂と銅箔の密着向上剤市場をメックが独占していると公式に認めている。これは「シェアが高い」ではなく「他に選択肢がない」レベル。

#### ② 致命的に重要な工程だから乗り換えコストが大きい

ニッチだが**致命的に重要な工程**を担っており、安い模倣品を採用すると：

- 顧客側（イビデンなど基板メーカー）の**再評価が必要**
- 評価には**コストと時間**がかかる
- その間の歩留まり悪化リスクは顧客が負う

→ **顧客にとって乗り換えの動機がほぼ無い**

#### ③ そもそもメックの薬剤は原価の小さな割合

PKG基板の原価に占めるCZシリーズの割合は低いと考えられる。だから安さで乗り換えるインセンティブが弱い。**「ニッチで重要で安い」という最強の組み合わせ**——これがメックの参入障壁の正体。

---

### 3-2. 粗利率の高さ：密着向上剤75%、エッチング剤45%

- 密着向上剤とエッチング剤の売上が全体売上のほとんどを占める
- 密着向上剤の方が利益率が高い
- 密着向上剤とエッチング剤それぞれの売上と全体粗利は公開されている → **四半期ごとに方程式立ててプロット**

結果：

| 製品 | 粗利率 |
| :---- | :---- |
| **密着向上剤（CZシリーズ）** | **75%** |
| エッチング剤 | 45% |

GPU向けCZ売上の構成比が上がるほど、**全社の粗利率が押し上げられる**。24/12の60.9% → 27/12の66.5%という改善は、この構成比変化が効いている。

---

### 3-3. 生産キャパ：物理的な余力がたっぷりある

```
単純計算で（出荷量 / 生産キャパ）= 稼働率
 → 現在は43%で、かなり余力がある
 
26年12月に本格稼働する新工場は生産キャパを3割増
（既存97,200トン → 新工場込みで127,200トン）

供給責任があるためmax稼働率は7〜8割
```

| 年 | 生産量(トン) | 工場キャパ(トン) | 稼働率 |
| :---- | :---- | :---- | :---- |
| 24/12 | 42,075 | 97,200 | 43.3% |
| 25/12 | 47,153 | 97,200 | 48.5% |
| 26/12 | 57,084 | 97,200 | 58.7% |
| 27/12 | 68,379 | 127,200 | 53.8% |

**「需要は伸びるけど作れない」が成長企業の典型的なボトルネック**だが、メックの場合は物理的な余力がたっぷりある。新工場が26/12に稼働開始することで、27/12以降のさらなる伸びも吸収できる。

## 4️⃣ バリュエーション（概要）

詳細な数値・EPS分解・シナリオ別計算はバリュエーションシート参照。

| 指標 | 数値 |
| :---- | :---- |
| **目標株価** | **7,443円** |
| 投資期間 | 26/12通期決算発表まで（約1年） |
| 売上高 | 24/12 18,234百万円 → 27/12 27,561百万円（**+51%**） |
| 営業利益 | 24/12 4,562百万円 → 27/12 9,465百万円（**×2.1倍**） |
| 営業利益率 | 25.0% → 34.3% |
| 純利益 | 24/12 2,291百万円 → 27/12 7,099百万円（**×3.1倍**） |
| 投資期間内（27/12まで） | 純利益 ×3.1、株価 ×1.6目安 |

なぜ純利益が×3.1倍になるかというと：

1. 売上が+51% → 営業利益が+107%（**営業レバレッジ**）
2. 加えて法人税率が **49.8% → 25.0% に正常化**（24/12は特殊要因）
3. その結果、純利益は売上の伸びを大きく上回る

つまり「**売上成長 × 利益率改善 × 税率正常化**」の三段ロケットが効く。

## 5️⃣ Appendix

---

### A. 投資期間の根拠：なぜ「26/12通期決算発表まで」なのか

**26/12通期決算発表まで（1年）を想定**。

※バリュエーションしているのは27/12まで

#### 理由

- **26/12は増収率が停滞するから**（25/12 +9.8% → 26/12 +17.6% → 27/12 +17.0%だが、純粋な薬剤需要の伸びは26/12付近で一旦頭打ちに見える）
- **26/12は工場稼働による人件費がのり、営利率の伸びが鈍化するため**（新工場で27/12に減価償却2.25億がのる）
- **半導体マクロに対する不透明感**（27/12以降を読み切るのは難しい）

つまり「**ストーリーが市場に伝わって株価が反応する**」までの期間として1年が現実的、というロジック。

---

### B. アップサイド①：増配 / 自己株買い

会社の財務余力から、増配や自己株買いがアップサイド要因となりうる。利益が×3になる中で、増配や自己株買いに踏み切れば株価の上振れ余地が出てくる。

---

### C. ダウンサイド①：半導体マクロの減速

GPU需要そのものが急減するシナリオ。これは投資期間の最大リスク。

→ ただし**投資期間が1年**なので、その間にAIサーバーの半導体マクロが急減速する可能性は低い。**まぁ大丈夫**。

---

### D. ダウンサイド②：ガラス基板の採用 / 無粗化へのシフト

技術的には密着向上剤を不要にする方向の動きはありえる：

- **ガラス基板**（樹脂ではなくガラスを基板に使う）
- **無粗化技術**（銅箔表面を粗化せずに密着させる別技術）

これらが普及すればメックの主力製品は不要になる。

→ ただし製造現場での実装には時間がかかる。**まぁ一年以内にはない**。

---

### E. 原材料リスクについて

IR電話：「**原材料は企業秘密だが、ナフサのような価格変動が激しい材料では無い**」

→ 原材料価格変動による粗利率の急激な悪化リスクは低い。粗利率75%（密着向上剤）が原材料起因で大幅に落ちるシナリオは想定しなくていい。
