## 0️⃣ 発表サマリー

### 一言で言うと

**メックはパッケージ基板の銅箔向け薬剤（密着向上剤＝CZシリーズ）を製造販売しており、その市場を独占している。GPU向けのパッケージ基板は通常基板に比べて層数が2〜3倍・面積が10〜15倍であり、今後2年でさらに面積が2倍になる。1年で純利益は1.4倍、株価は1.6倍になる。よってBUY！！！**

---

### 成長を因数分解する

CZシリーズの売上は以下のように分解できる。

```
CZ売上 = 汎用（スマホ・パソコン）向け + GPU用PKG向け

GPU用PKG向け = 前年売上 × GPU生産伸び × 面積増加率 × 層数増加率 × 使用量補正
```

| 因数 | 方向 | なぜ動くか |
| :---- | :---- | :---- |
| **GPU生産伸び（基板生産数YoY）** | ↑ 25/30/20/10% | AIサーバー需要。電力制約での鈍化も織り込み |
| **銅箔面積（mm²）** | ↑ Hopper4,000→Blackwell7,500→Rubin12,000 | NVIDIA世代交代で大判化 |
| **銅箔層数** | ↑ 12→14→18層 | 信号・電源密度の上昇でz方向に多層化 |
| **使用量補正** | 50%固定 | GPU向けは多層化のため可能な限り薄く粗化（汎用の半分） |
| **汎用向け** | 横ばい（CAGR 0%） | 成熟市場。バリュエーションでは伸びを織り込まない |

**核心の結論**：GPU向け基板1枚あたりの薬剤消費は、面積（mm²）×層数の積で増える。Hopper→Blackwell→Rubinの世代交代だけで1枚あたり消費量は数倍に膨らむ。CZ売上はGPU生産台数の伸び以上の速度で拡大する。

### CZシリーズとは

**パッケージ基板製造時に必須**の薬剤。これが無いと銅箔と樹脂の界面が剥がれて端がめくれたりして歩留まりが悪化する。

#### CZシリーズの生誕ストーリー

```
1990年代、基板の材料がセラミック → 有機樹脂に切り替わった
   ↓
「銅箔と樹脂が剥がれる」という新しい問題が浮上
   ↓
メックが銅の表面を粗化することで密着度を高める手法を提案
   ↓
その後デファクトスタンダード化した
```

つまり「業界の根本的な問題を解決した会社」であり、規格そのものを握っているポジション。

---

### 半導体パッケージ基板とは

半導体とPCB基板（マザーボード）をつなぐ中継機。

- パッケージ基板を作るプレイヤーは**イビデン、新光電気工業など**
- メックはこれらのプレイヤーに薬剤（密着向上剤）を販売している
- イビデンはメックの過去のIRレポートに名前が出ている納入先で、**生産量大幅増強を打ち出している**

---

### 今後パッケージ基板は「大判化」と「多層化」が進む

**HBMというメモリ部分とSoCというロジック部分は数が増えて大きくなる**

→ それに伴いパッケージ基板（Substrate）が大型化（大判化）

→ さらにビルドアップ層もコア層も多層化が進む

#### なぜ多層化が必要か

- そもそもパッケージ基板は「GPU側とマザーボード側の電源や情報の中継機」
- AIサーバー向けGPUは、汎用CPU/GPUに比べてやりとりする情報や必要とする電源が大きくなる
- 既にサイズが規格化されている以上、**z方向（縦方向）に増やしていくしかない**

## 2️⃣ マクロ：パッケージ基板の大判化・多層化が引き起こす薬剤需要の構造変化

### 2-1. GPU向け基板生産数（YoY）

- 汎用（スマホ・パソコン）向け：CAGR 2〜3%程度の成熟市場 → **バリュエーションではCAGR 0%とした**
- AI用途GPU向け：各種レポートを参考にし、電力制約などによる成長率鈍化の可能性も織り込み、**2025〜2027でそれぞれ30%、20%、10%**とした

### 2-2. 現時点の基板生産数の比率

```
生産台数/年
 ① スマホ：12.2億    ② パソコン：2.65億    ③ AIサーバー：181万

パッケージ基板数
 ① スマホ：10        ② パソコン：15        ③ AIサーバー：120
```

→ 用途別のパッケージ基板生産数の比は

**汎用（スマホ・パソコン）向け：GPU向け ＝ 60：1**

---

### 2-3. 銅箔面積：GPU向けは「大判化」で爆発

#### 汎用（スマホ・パソコン）向け

- スマホ用パッケージ基板：パソコン用パッケージ基板 ＝ 4：1
- スマホ用：150〜200mm² / パソコン用：700〜1,000mm²
- **加重平均で 310mm²**

#### GPU向け：インターポーザーだけでも大判化

| 世代 | インターポーザー面積 | 余白込み（仕様） |
| :---- | :---- | :---- |
| Hopper | 2,831 mm² | **4,000 mm²** |
| Blackwell | 4,719 mm² | **7,500 mm²** |
| Rubin | 7,722 mm² | **12,000 mm²** |

各種レポートで予想されるレンジ。

---

### 2-4. 銅箔層数：GPU向けは「多層化」で増える

#### 汎用（スマホ・パソコン）向け

- スマホ：4 / パソコン：1 の比率
- スマホ：5層 / パソコン：11層
- **加重平均で 6.2層**

#### GPU向け

モルガン・スタンレーのレポートを元にバリュエーション：

| 世代 | 層数 |
| :---- | :---- |
| Hopper | 12 |
| Blackwell | 14 |
| Rubin | 18 |

#### Hopper / Blackwell / Rubin の比率推移

| 年 | Hopper | Blackwell | Rubin |
| :---- | :---- | :---- | :---- |
| 24/12 | 50.0% | 50.0% | 0.0% |
| 25/12 | 20.0% | 80.0% | 0.0% |
| 26/12 | 10.0% | 70.0% | 25.0% |
| 27/12 | 5.0% | 20.0% | 75.0% |

---

### 2-5. 使用量補正

GPU向けは多層化のため可能な限り薄く粗化する：

- 汎用向け：CZ8101
- GPU向け：CZ8201

GPU向けは汎用向けに比べて使用量は**半分（50%）**になる。

## 3️⃣ ミクロ：なぜメックがこの需要を独占できるのか

### 3-1. シェア：市場独占

- **メック自身や経産省も**パッケージ基板の樹脂と銅箔の密着向上剤市場を独占していると認める
- **ニッチだが致命的に重要な工程**を担っており、安い模倣品を採用すると顧客側の再評価が必要でコストや時間がかかる
- そもそもPKG基板の原価に占める割合は低いと考えられ、安さで乗り換えるとは思えない

### 3-2. 粗利率の高さ

- 密着向上剤とエッチング剤の売上が全体売上のほとんどを占める
- 密着向上剤の方が利益率が高い
- 密着向上剤とエッチング剤それぞれの売上と全体粗利は公開されている → 四半期ごとに方程式立ててプロット

結果：**密着向上剤：75%、エッチング剤：45%** と置いた。

### 3-3. 生産キャパ：余力あり

```
単純計算で（出荷量 / 生産キャパ）= 稼働率
 → 現在は43%でありかなり余力がある
 
26年12月本格稼働の新工場は生産キャパを3割増
供給責任があるため max稼働率は 7〜8割
```

需要が伸びてもキャパ制約で売上が頭打ちにならない。

### A. 投資期間の根拠

※バリュエーションしているのは27/12まで

- 半導体マクロに対する不透明感

### C. ダウンサイド①：半導体マクロの減速

→ 投資期間1年なのでまぁ大丈夫

→ まぁ一年以内にはない

IR：「原材料は企業秘密だが、ナフサのような価格変動が激しい材料では無い」

→ 原材料価格変動による粗利率の急激な悪化リスクは低い
