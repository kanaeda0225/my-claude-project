## 3. 光電子事業を「事業として」サイジングする

### 3-1. 損益分岐点の試算

過去2期の数値から:
- FY3/24: 売上¥2,042M、OP▲¥669M → 営業赤字率 -32.8%
- FY3/25: 売上¥2,510M、OP▲¥355M → 営業赤字率 -14.1%
- 1H FY3/26: 売上¥1,276M、OP▲¥69M → 営業赤字率 -5.4%

線形外挿で**売上 ¥2,700-2,900M 程度で営業損益ブレークイーブン**になりそう。
通期FY3/26の売上は1H ¥1.276Bから年率換算で**¥2.6B前後**と推計され、まだ若干赤字だが**FY3/27にはほぼ確実に黒字化**するスロープ。

### 3-2. ベース／ブル試算（黒字化後）

事業の固定費がほぼ無くなった後、追加売上の貢献度を概算（典型的なフォトニクス事業マージン15-25%を想定）:

| シナリオ | FY3/30 売上見立て | OP（margin 15-20%） | 全社OPへの追加寄与 |
| :- | -: | -: | -: |
| Bear（横ばい） | ¥3B | ¥0-0.3B | ほぼゼロ |
| Base（800G/1.2T本格化） | ¥6-8B | ¥1-1.5B | +5-10%（全社¥10-13Bベース） |
| Bull（1.6T+TFLN獲得） | ¥15-20B | ¥3-4B | +20-30% |
| Super Bull（CPO直接受益） | ¥30-50B | ¥6-10B | +50%以上 |

**Baseすらまだ立証されておらず、Bullは執行リスク（量産投資が¥103M/年では足りない）**。
SuperBullは現中計の設備投資配分とは整合しない（新材料に偏重しているため）。

### 3-3. 光電子事業の「真のサイズ」を市場と比べて

- Lumentum全社売上 $1.65B = ¥247B（円換算）。LN変調器単独のサイズは推定 $200-500M = ¥30-75B
- SOC光電子 ¥2.5B / Lumentum LN変調器 ¥30-75B = **シェア3-8%**
- SOCのLN結晶（材料）シェアは別途高いが、デバイスとしてはニッチプレイヤー

**「世界シェア70%神話」は LN結晶供給ベースの話で、デバイス売上シェアではない**。これが v1メモでの私の重大な誤認だった。

## 4. 「株価が動かない」理由（再評価）

| 仮説 | 一次資料での検証 | 判定 |
| :- | :- | :- |
| ① 光通信プレミアム未織り込み | 売上比率1.1%、まだ赤字 → 業績インパクトが小さい | △ そもそも織り込むほどの規模ではない |
| ② セメント値上げ織り込み余地 | FY3/25 セメントOP -¥1,435M → +¥877M、1H FY3/26 +¥1,702M好転 | ○ 主役はここ、既に株価に反映 |
| ③ 中計目標未達 | ROE 4.7% vs 目標8%、ROIC 2.4% vs 目標5% | ○ 大幅未達がPBR<1x の根拠 |
| ④ 新材料に賭けすぎ | 設備投資 ¥3,913M / 光電子 ¥103M = 38倍 | ○ 半導体材料相場次第になっている |
| ⑤ アナリストが光通信を理解していない | 直接の「CPO」「TFLN」言及が有報になく、SOC自身がアピールしていない | ○ 但しSOC側からの発信不足が原因 |

**結論**: 株価が伸びない理由は構造的かつ正当。「光通信銘柄として再評価される」ためには、**会社自身が光電子事業の数値KPIをコミットして開示する必要**があり、現状の中計開示ではそれが起きていない。

## 5. 投資テーゼの最終形（v2）

### 不成立になったテーゼ
- ✗ 「光電子事業がOPの20-30%を稼ぐ隠れた利益柱」 — 完全な誤り、実態は赤字
- ✗ 「世界シェア70%のLN変調器pure-play」 — 結晶では強いがデバイスはニッチ

### 成立しうるテーゼ

**Thesis A: セメント値上げ織り込み余地（光電子はオマケ）**
- セメントOPが▲1.4B → +0.9B → 1Hで+0.04B（半年で大幅好転）
- 通期FY3/26は会社計画 OP ¥19B 程度
- PBR 0.63x の修正余地
- ROE 8%目標達成シナリオでP/Bが1xに戻れば株価+60%
- **光電子はストーリーには使えるが数値貢献は限定的**

**Thesis B: 光電子の「赤字脱出 × 800G/1.2T立ち上がり」変曲点**
- 過去2年でOP -¥669M → -¥355M → 1H -¥69M と一直線の改善
- FY3/27 黒字化が射程
- 800G/1.2T LN変調器は商品化済み（量産タイミング）
- 1.6T は要素技術開発フェーズ → 2027-28
- 利益貢献の絶対額は小さい（数億円〜十数億円規模）が、赤字解消は心理的に効く
- **株価インパクトとしては、Thesis A の従属変数**

**Thesis C: 光電子 + 新材料の合算で見る「半導体周辺企業」テーゼ**
- 新材料(半導体材料/静電チャック)OP ¥2,264M はAI半導体投資の恩恵
- 静電チャックは生産能力増強中、量産安定で利益拡大余地
- 光電子は付録だが「光×AI」の合わせ技で投資家にアピール可能
- **これが現実的に瀧本ゼミで通る「数字で詰められても崩れない」テーゼ**

### おすすめは Thesis C

光電子事業単独では絶対額が小さすぎる。**「光電子+新材料」の合算（FY3/25で売上 ¥18.2B、OP ¥1.9B）= 全社売上の8.3%、OPの20%**として捉えれば、AI/光通信プレミアムを正当に乗せられる。
