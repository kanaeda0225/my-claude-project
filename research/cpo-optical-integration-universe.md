# 光電融合 / CPO（Co-Packaged Optics）関連 日本上場銘柄ユニバース

> マクロテーゼ:
> - AIデータセンターの電力ボトルネックが深刻化（NVIDIA NVL576で1ラック1.4MW）
> - サーバ内・ラック内の銅配線 → 光配線への置換で電力を桁違いに削減（CPO化）
> - 2026〜2027年が量産・実用化の変曲点（三井物産戦略研究所）
> - Broadcom／NVIDIAが製品化ラッシュ、NTT IOWNが2026年Q4商用サンプル提供開始予定
> - 産総研「光電融合研究センター」2025年4月設立、高市政権の所信表明にも言及
> - 織り込み度は「中」。AI半導体・電力ほど買われていないが、26年からPL効果が顕在化

## 1. バリューチェーン全景（CPOに何が要るか）

```
[電気]                                              [光]
  AI ASIC (Broadcom/NVIDIA)                       External Light Source (ELS)
       │                                                    │ CW Laser
       ▼                                                    ▼
   ┌───────────────────────────────────────────────────────────┐
   │  CPO Package (大型有機/ガラスインタポーザ)                  │
   │  ┌──────────┐   ┌────────────┐   ┌──────────────┐         │
   │  │  ASIC    │←→│ Si Photonic │←→│ Optical I/O   │ → ファイバ
   │  │ (SerDes) │   │  Engine    │   │ (PIC + Edge   │
   │  └──────────┘   │ (Mod/Det)  │   │  Coupler)     │
   │                 └────────────┘   └──────────────┘         │
   │           InP/GaAs EML & DFB Laser  ←  外部光源or統合       │
   └───────────────────────────────────────────────────────────┘
                                  │
                                  ▼
                          MPO/MTPコネクタ → 細径光ファイバ → スイッチ
```

各レイヤの日本上場プレイヤを下記で網羅する。

## 5. 補論：「光電融合」と「CPO」は同義ではない

| 用語 | 主体 | スコープ |
| :- | :- | :- |
| **CPO** | 米半導体ベンダ（Broadcom/NVIDIA/Marvell） | ASICパッケージ内に光エンジンを同梱 |
| **光電融合デバイス** | NTT/IOWN Global Forum | サーバ内・チップ間・チップ内まで光化する長期構想 |
| **APN** | NTT | DC間〜DC内のオール光ネットワーク |

→ どちらも「銅→光」「電力削減」「26〜27年で量産」という共通課題を持つため、本ユニバースでは両者をまとめて扱う。
